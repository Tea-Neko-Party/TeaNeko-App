# 本地 Skill

Skill 是有版本的流程参考，通过本轮目录按需读取正文，沿用原 LLM 工具循环。它不授予工具、平台或 DEBUG 权限，也不直接执行文件或代码。

## 启用与使用

已登记且启用的作用域默认关闭 Skill。OWNER 可使用原 `/cfg` 设置：

```text
/cfg set agent skills clear-explanation
/cfg set agent skillsEnabled true
/agent skills
/agent chat 请分步骤解释这个问题
```

`skills` 为最多八项的显式名称列表，英文逗号分隔；不支持 all、路径或类名。内置 `clear-explanation` 示例无需额外工具，可直接体验。模型先看到名称、说明、版本及依赖，再按需调用 `skill_load`；不用的 Skill 不加载正文。一次加载也消耗原工具执行次数和工具往返，后续模型继续使用同一总预算，不另开交互。默认三次模型请求可完成“加载 Skill → 调用其依赖工具 → 最终回答”。

依赖必须已在当前实例、作用域及请求的实际工具集中。缺少依赖、名称冲突或已禁用条目会明确拒绝该轮，不从全局目录自动补工具。原工具仍独立校验实际角色、scope、开关和业务条件。

## 本地目录及更新

本地 Spring 配置：

| 配置项 | 默认值 |
| --- | --- |
| `tea-neko.agent.skills.enabled` | true；仍须作用域显式开启 |
| `tea-neko.agent.skills.directory` | config/agent/skills |
| `tea-neko.agent.skills.builtin-example` | true；加入内置示例 |

管理员将文件安装到根目录下的 `<名称>/SKILL.md`，只有一层目录会被读取。文件内容示例：

```markdown
---
name: memory-review
description: 核对当前空间的明确记忆后回答问题。
version: 1
enabled: true
requires-tools:
  - memory_query
---
# 核对记忆

先用当前已授权的 memory_query 查询相关证据；保留主体和来源。
证据不足时说明不确定之处，不把推断写成个人事实。
```

名称必须与目录一致，为小写字母开头的字母、数字或连字符，最多四十八位；说明最多 256 字符，版本为正整数。`enabled` 默认 true，`requires-tools` 默认空列表、最多十六项；未知字段、重复 YAML 键、多文档、非法 UTF-8 和重名会拒绝整个候选目录。正文非空且最多 3000 字符，单文件最多 64 KiB，目录最多六十四个 Skill。头部不接受任意配置、密钥或执行器。

本地文件安装和修改由可信管理员完成，路径不能经聊天配置。更新文件后，真实 DEBUG 在已启用作用域执行 `/agent reloadskills` 才发布新快照；OWNER 可以选择已经安装的 Skill，不能借选择安装或更新文件。关闭内置示例后可在本地安装同名版本，内置与本地重名时明确拒绝覆盖。

加载期间不执行文件内代码，不递归扫描其他路径，不跟随越界链接。全部文件校验及发布前授权复核通过后才原子替换目录；失败保留上一完整快照。构造服务不读盘，未启用 Skill 的普通轮次不加载目录。

## 快照、历史与重放

目录指纹覆盖元数据、正文、启用状态和依赖；修改正文而忘记改版本仍会换代。同轮 Prompt、加载器及实际正文必须匹配同一指纹。重载改变目录内容、关闭或更换作用域选择后，旧轮在模型、工具及交付前被拒绝；原完成重放也只读复核当前策略，不重新加载正文或重做工具。

目录片段参与原完整输入预算；片段被整项省略时，本轮不注册隐藏加载器。工具结果完整保留在该轮诊断中，提交历史时仅将声明为临时结果的正文替换为占位文本，保留工具调用及 ID 配对。后续有需要时重新加载，避免旧流程正文持续堆积在窗口、摘要或下一轮输入中。其他工具结果沿用原历史规则。

宿主可替换 ISkillCatalog、ISkillPolicy，或通过 AgentSkills 装饰自有 Prompt 和工具源。底层只增加读取实际 Prompt 布局的工具选择入口，以及可声明临时工具结果的纯数据投影；没有额外模型循环、轮次全局缓存或任意宿主执行器。

离线验证覆盖实际文件、完整工具往返、共享预算、依赖拒绝、重载/停用及重放失效、历史投影与真实命令权限。模型是否选择合适流程和实际表达质量仍需真实模型验收。
