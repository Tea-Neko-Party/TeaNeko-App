# 三层持久记忆与自动画像

三层记忆、观察式人格、显式保存、平台回执与到期维护已经接通；初始交付记录见[实施归档](../../../../../../../../../docs/plan/old/4.6.1-layered-memory.md)，本次阶段计时修正见 [v4.8.3-l](../../../../../../../../../docs/changelog/4.8.3-l.md)。

默认完整装配将 teaneko.agent:layered-memory 和 teaneko.agent:long-memory 安装到使用默认能力的实例。显式选择 features 的实例需分别加入所需能力，才能向模型提供恢复资料和长期工具。

## 实际数据与行为

短期记录和原历史记录在同一个 EasyData 事务提交；任何写入失败一起回滚。每条消息保存原作者 UUID、完整 client/scope、实际事件时间、角色和采集时人格；来源重投不增加序号或延长保留期。短期分区包含 namespace、绑定版本和 generation，不包含人格身份，因此单纯换人格仍可追溯原消息。

近期资料默认只来自当前 scope，标明来源和精确时间。USER 是收到的发言；ASSISTANT 原记录只表示生成答案。近期注入叠加实际平台回执：ACKNOWLEDGED 表示全部分段确认，PARTIAL 只展示已确认正文，UNKNOWN 不展示未确认的候选；没有回执的旧记录明确为 GENERATED_UNCONFIRMED，不能当作用户自述或成功发送。

每次最多读取 24 条近期消息和 6 段中期片段，分别最多装入 6000 字符的完整资料；单项过长时省略，不截断成另一句话。近期注入排除当前原文和已被中期覆盖的消息。资料由原 Prompt 总预算决定最终采用，有限窗口不代表完整历史。重启后从数据库读回，不恢复旧模型调用、工具副作用或未完成发送。

中期片段记录固定源序号区间、输入指纹、事件范围、简短及详细摘要、实际生成时间。普通时间显示概略月份，重要日期由摘要保留原精度；处理时间不能冒充事件发生时间。资料只作为 USER 参考数据，继续接受当前开关、原引用、片段有效期和插件版本复核。

## 自动压缩及恢复

后台在原调度器扫描持久分区目录，最多一个在途压缩任务。未处理消息达到数量阈值，或可压缩旧段达到字节阈值时领取任务，保留最新若干消息。通过原 SUMMARY 活动门控执行一次无工具 LLM 请求，预算独立于前台，仍受原模型能力和 token 预检限制。

领取的连续输入和租约写入数据库。摘要模型同时取得有界送达回执，部分成功只采用已确认部分，不把候选答案记成已经说出的话；确认只代表平台接受，不代表收件人已阅读。生成后复核原消息指纹、代次、租约和原始保留期；摘要必须符合结构、容量并缩小输入。中期片段与压缩水位同事务提交；其间新追加的尾部不会阻止原前缀提交。旧租约、clear 后的旧代次或策略撤销均不能交付迟到结果。

中长期生成的输出 token 上限统一使用所选模型配置的 `max-tokens`，不再设置额外业务上限或隐含总 token 配额。`max-input-bytes` 继续限制完整输入的保守字节估算；真实调用另按模型 `context-window-tokens` 与 `context-input-ratio`（默认 0.8）检查上下文，并为完整输出额度保留空间。输入或显式预算不足时在请求前拒绝，不自动调低输出上限。中期摘要仍须符合正文长度和压缩要求；模型输出截断按失败处理，不解析不完整 JSON。

领取后的失败不推进水位，普通故障按 30 秒起步、最长一小时的间隔退避；次数计入持久状态。长期整理对同一输入的无效生成另有暂停阈值，见下节。原始数据仍按保留期维护，重启不丢失未完成状态。关闭停止调度并结束自有控制，原模型或数据库已经发生的工作不因此承诺回滚。

领取前的目录或分区读取失败采用独立的进程内退避：30 秒起倍增，最长一小时，成功读取后清除该阶段计数。冷却期间不重复读取或告警；长期领取失败仍可检查本分区的中期压缩，其他分区继续处理。最多跟踪 1024 个失败目标，超出时共同限频；扫描控制或退避保存本身失败时暂缓整个处理器。此状态重启后重置，不写入不可解析的记录，也不表示跳过或完成该批次。

目录扫描与领取后的整理分别计时，扫描耗时不占用模型整理时间。批次超时只报告实际批次阶段，不重复报成目录扫描失败；退避或已发起的提交须按真实持久结果结束后，调度器才释放在途占用。真实模型响应超过时限仍会保留原数据并退避重试。

中长期生成统一使用[类型化 JSON 服务](../../llm/framework/structured/README.md)。长期整理顶层固定为 `{"memories":[],"styles":[]}`；未提供人格目标时 `styles` 为空数组。自动类型描述参与输入预算，格式或证据失败不推进水位。日志报告字段、行列及脱敏结构；需要核对原文时按共用说明临时开启受限本机归档。

原始消息到期后不再用于新摘要；已过期源的跳过位置和成功压缩水位分别保存，不能声称过期消息已被记住。后台维护逐批回收已到期正文，原历史清理继续独立运行。没有足够旧消息的近期尾部继续留在短期，不强制每轮调用模型。

## 配置

前缀 tea-neko.agent.memory.layered.：

| 参数 | 默认值 | 含义 |
| --- | ---: | --- |
| enabled | true | 启用分层资料和后台压缩；不替代原历史采集开关 |
| trigger-messages | 12 | 未处理消息数量触发阈值 |
| trigger-bytes | 32768 | 候选旧段紧凑 JSON 字节触发阈值，与数量条件满足其一即可 |
| keep-messages | 4 | 压缩时保留的最新原始消息数 |
| batch-messages | 16 | 单次压缩的连续消息上限 |
| max-input-bytes | 131072 | 中长期模型完整输入的保守字节估算上限，包含元数据、JSON 包装与固定开销 |
| timeout-seconds | 45 | 目录扫描、领取后的整理分别使用此时限；已发起的持久提交和退避等待实际结果 |
| retention-days | 90 | 中期片段可用于注入的保留期 |
| poll-ms | 5000 | 目录扫描周期 |

压缩沿用 scope 的 historyCaptureEnabled 和 autoSummaryEnabled；近期读取同时要求 historyReadEnabled 和 memoryReadEnabled，原 Agent 登记和启用仍是前提。长期读取要求 memoryReadEnabled，学习要求 memoryLearningEnabled，本人维护要求 memoryAddEnabled。新建 scope 的 memoryLearningEnabled 默认 true；已有数据库中显式保存的 false 继续生效，需要自动学习时通过原配置入口开启：

```text
/cfg set agent memoryLearningEnabled true
```

本地 tea-neko.agent.memory.long-term.enabled=false 可同时关闭新长期生成、读取和维护；关闭 layered.enabled 也停止新长期功能，不改动旧事实和旧人格。关闭学习不删除现有长期记忆，不阻止已经允许的短期采集。

人格观察沿用独立 personalityLearningEnabled；开启观察后，即使关闭 memoryLearningEnabled，后台仍可消费新中期片段的合格人类表达，但不会提交事实候选。默认开启的联合分析不会额外调用一次模型；没有当前人格合格样本且事实学习关闭时，直接完成空筛选。观察具体规则、查看工具和回退方式见[人格说明](../../personality/README.md#持久观察式人格)。

默认分层装配启用时停用旧内存摘要生成，避免重复消耗同一聊天。关闭分层功能，或独立宿主未装配分层存储时，原内存摘要保留。

## 数据和扩展

数据继续放在 tea_neko_agent_data 的 agent.memory.layers.v1 域：short: 保存消息，source: 防重，streams 为恢复目录，states 为租约与水位，medium: 为片段。业务只访问专用 EasyData DTO，不直接操作 Repository。

长期数据位于同表的 agent.memory.long.v1 域。共享键只包含 namespace 与 generation；来源 client/scope 和绑定版本保存在证据链，不用于隐式过滤长期召回。jobs 保存整理租约、水位、失败状态和管理版本；job-replays: 保存按空间代次和聊天隔离的恢复回执。entries: 为权威记录，subject:/term:/recent:/family: 为索引，changes: 为本人操作回执，blocked: 为旧证据抑制。content: 为同主体原文索引，explicit: 保存明确动作回执，explicit-values: 保留明确条目的完整附加信息及有效期。原事实与人格域继续保留，不将旧事实自动导入新索引。

## 明确保存与平台回执

默认轮次在模型前识别当前真实用户原文的“记住/请记住”前缀，冒号可省略；通过原可信记忆访问边界完成保存后才继续。关闭 historyCaptureEnabled 或 memoryLearningEnabled 不关闭明确保存，memoryAddEnabled 仍须开启。原文按 FACT 保存到同一长期领域，工具复用原操作回执；同主体同正文跨类型去重，人工纠正、遗忘、锁定及过期保护继续有效。独立宿主和开关回退见[访问契约](../access/README.md)。

命令、自动回复与自主发言通过 AgentDeliveryService 等待逐段账本和实际传输。agent.delivery.v1 的 receipts: 分区按完整 scope、绑定和空间代次隔离，发送前占用，取得有效平台消息 ID 后确认；失败保守记为 UNKNOWN。下一段只在前段实际完成后启动，每段仍复核原授权与目标。已有 ACKNOWLEDGED 重放跳过传输，未决或冲突占用拒绝自动补发，重启不恢复外部发送。

回执只保存有界已发送文本投影或图片占位与完整内容摘要，不保存图片数据或链接；使用原历史 retention-days，默认七天，由同一维护调度回收过期及旧代次。取消、断网和数据库写入失败不证明平台没收到，也不能撤回已发内容。普通服务调用没有平台发送时保持未确认状态；真实人类事实仍只从 USER 原话提取。

## 到期维护与旧代次回收

维护独立于采集和学习开关；关闭学习、分层注入或长期读取不延长已保存数据的有效期。默认每十秒串行维护实际实现 IMemoryMaintenance 的数据域，前批未结束不重叠启动，不调用模型。单域失败时回滚该域的变更及游标，其他域仍可继续；重启从已提交进度恢复。倒序域分页在到达末页后轮转，持续新增数据不会无限延长当前扫描轮。

```properties
tea-neko.agent.memory.maintenance.enabled=true
tea-neko.agent.memory.maintenance.interval-ms=10000
```

短中期每批维护一个分区，扫描至多十六条短期与八段中期。短期正文和来源索引一起回收，当前分区保留 last 序号、水位和作业，新的消息不会重新从一开始编号。未压缩消息只回收已处理区间或连续到期前缀，避免删除中间行破坏后续压缩；被有效前项挡住的到期消息会在后续压缩或前项到期后回收。原始消息到期不撤销已经合格的长期结论。中期按当前保留期回收，租约内已经到期或被回收的来源不能迟到提交。

长期每批最多检查八个域内记录。当前代次仅精简到期原话、修正失效索引，保留事实正文、公开版本、来源摘要、人工锁定、遗忘墓碑和幂等回执。已 clear 的旧 generation 逐批回收正文、作业、索引、旧回执及旧墓碑；不清除当前代次，也不通过重新绑定改变原任务目标。原话精简不改变公开内容 revision，不使正在使用的同内容资料无故失效。

agent.memory.lifecycle.v1 保存空间/分区的无正文定位标记，新采集同事务登记，已有分区在维护时补登记。原目录删除后仍可判定旧作业和共享索引归属；未知归属保守保留，不猜测后删除。定位标记不含对话、密钥或用户事实，继续保留用于安全维护。旧 namespace 的原 fact 管理回收入口不变。

人格观察按原保留期精简样本，失效模式回收后保留无原话的采用水位；可写人格集合释放到期补正容量，不改动不可变备份。具体边界见[人格说明](../../personality/README.md#持久观察式人格)。关闭维护只暂停物理回收，不让到期内容重新可读。关闭服务不声称取消已经开始的数据库事务。

## 从中期到长期

同一后台处理器先整理已就绪的中期片段，再压缩旧消息；两个阶段共用单个在途任务、一次模型调用和总时限。每批最多四段；一段空闲十分钟后也会进入整理。生成走原 LEARNING 活动及统一模型交互，无工具，输出事实、偏好或事件；有当前人格样本时，联合对象包含 memories 和 styles 两个数组。空候选也是有效的完成结果。重复运行不会再学习已完成水位之前的闲聊，关闭的学习域不会在未来重启时自动补学已跳过旧段。

事实和偏好必须引用对应作者的真实 USER 消息连续原话。模型输入提供证据—作者—片段映射；生成预检与提交事务共用关系校验，事务另回查权威消息、保留期、人格和租约，期限包含事务排队耗时。任一事实或风格候选无效，整批事实、风格、索引和水位均不提交，不通过删掉错误项伪造空成功。助手答案不能变成用户事实。事件可以引用中期摘要，但 subjectId 为空，不冒充个人画像。普通召回只给公开结论、状态、版本和概略月份，不输出其他群原聊天或原话证据。重要时间必须逐字来自已核对的引用。

同主体、类型、属性、正文重复时合并来源；明确 REPLACE 且来源较新才替代同属性旧值，人工锁定或时间倒置时保留冲突，CONFLICT 不能作为确定结论使用。自动画像是当前主体有效事实和偏好的投影，不维护另一份无来源的画像正文。

普通聊天先注入至多八条本人画像，再补至多八条本轮关键词命中项，两个片段分别限四千字符并跨来源去重。索引最多扫描 256 个候选，受限时明确 limited，不把空页声称为完整不存在。当前是字面关键词检索，没有新增向量库。每次发送或重放前检查条目版本，已经纠正、遗忘或替代的旧资料不能继续采用。

非空查询没有产生索引词时，仍在有界候选内按原查询做字面匹配，例如“茶”“猫”“a”；只有真正空查询才列最近项，不用无关记录填充非空查询。

后台联合整理在真实提交事务入口及水位写入后执行生命周期守卫，并分别复核事实学习和人格观察资格；纯事实、仅风格及空候选都执行守卫。模型完成后、事务尚在队列中时发生的取消或撤权，会回滚本批写入，不推进整理水位。代次、租约与证据校验继续生效。

没有合格观察样本不等于观察已撤权。事实学习关闭但观察仍开启时，切人格、无可学习字段或证据到期产生的合法空筛选可推进；排队后真正关闭观察仍拒绝。

## 长期整理失败与恢复

日志使用固定原因，附候选域 `memories/styles`、从零开始的序号、请求/批次及证据短摘要，不输出原话、候选正文或任意异常消息。模型状态只报告实际取得的结果。

| 原因 | 含义与处理 |
| --- | --- |
| QUOTE_MISMATCH / SUBJECT_MISMATCH / SEGMENT_MISMATCH | 引用被改写、作者错配或证据不在所选片段；保留原批次，不放宽校验 |
| EVIDENCE_ID_INVALID / SEGMENT_OUTSIDE_BATCH / TIME_HINT_MISMATCH / STYLE_TARGET_MISMATCH | 候选引用、时间或观察目标不符合固定输入 |
| EVIDENCE_MISSING / EVIDENCE_CHANGED / EVIDENCE_EXPIRED / EVIDENCE_ROLE_INVALID / STYLE_TARGET_CHANGED | 来源已失效或不再合格，重新领取有效输入；不计入无效生成阈值 |
| INVALID_OUTPUT / OUTPUT_LIMIT | 输出结构不合法或被截断；检查模型协议、输出额度与上下文 |
| MEMORY_STORAGE_FORMAT | 持久数据与当前结构不匹配；日志给出记录类型与受控字段，保留原记录，不计为模型无效生成 |

同一固定输入累计三次候选关系错误、无效格式或输出截断后，作业持久标为 `PAUSED`，不再为相同输入后台调用模型。撤权、租约变化、来源失效和基础设施故障不计入该阈值。重启不清除暂停；不推进成功水位、不删除原证据，正常保留期仍生效。

工作区“三层记忆”显示状态、失败原因和次数。管理员确认原因后可按已读取版本“恢复整理”；操作保留幂等回执、当前空间代次和事务内授权复核，旧租约不可提交。恢复只解除暂停，不承诺模型已运行或已成功。固定前缀与可用证据的输入指纹变化后也可自动重新领取；只追加前缀之外的新消息不一定解除暂停。

旧 `jobs` 记录无须手工改写：缺失的管理版本按零读取，失败状态为空，原租约、水位和退避保留。独立存储可通过三参 `retry` 接收安全失败分类；原两参接口仍兼容。管理状态与恢复接口未实现时明确拒绝，不伪造支持。生成器未新增自动纠错调用，仍使用原预算。

其他格式错误不会被默认值覆盖。出现 `MEMORY_STORAGE_FORMAT` 时按日志核对版本与记录字段；工作区的“恢复整理”用于解除有效作业的生成暂停，不是修复损坏 JSON。原数据格式修复后，在下一次允许的读取时恢复处理。

## 注解工具与本人维护

所有 client 默认可用，仍要求实例允许 TOOL 活动、安装 long-memory 能力以及当前真实作用域权限：

| 工具 | 用途 |
| --- | --- |
| memory_search | 按 query、可选 subjectId 和 limit 检索当前共享 namespace 的自动及明确保存结果 |
| memory_user_profile | 默认读取当前用户的自动画像，可显式指定共享空间内的用户 UUID |
| memory_correct | 根据已查询的 id、revision 纠正本人条目，锁定人工结果 |
| memory_forget | 根据已查询的 id、revision 遗忘本人条目并留下墓碑 |

维护工具仅在本轮真实原文以“纠正/请纠正/更正/请更正”或“忘记/请忘记/删除记忆/请删除记忆”开头时提供；“你是不是忘记我了”不会授权删除。先查询目标，含糊时澄清，不能修改他人条目。真实用户 UUID、空间和来源从宿主取得，模型不能通过参数自报。回执与修改同事务保存，同一原工具调用重试返回相同结果，换参拒绝。

本人维护轮次不预先注入新长期画像，改由查询工具取得原版本，避免本轮维护成功后自动注入的旧版本让同一轮次失效。普通聊天仍检查已采用资料的原版本，不能把失效投影静默更新成其他内容。

纠正和遗忘保留原始聊天；派生抑制采用原主体/片段及真实平台消息来源。同一旧证据重新绑定、重导入或换正文也不能自动恢复已遗忘内容；同片段中该主体的其他候选以及依赖被抑制来源的事件也会保守跳过。新消息不自动解除人工锁定或恢复同一已遗忘正文。若要恢复，需通过明确的本人纠正操作；本批没有整库自然语言删除或跨用户维护能力。

ILayeredMemoryStore 和 ILayeredMemoryCompressor 分离持久化与生成；可以替换摘要后端，不重写调度器。自定义存储须同时提供可靠采集适配，不能仅替换读取端口后假定默认历史事务会为其写入。旧独立 EasyDataHistoryStore(data, mapper) 构造保留原语义，不自动采集新分层数据。

ILongTermMemoryStore 与 ILongTermMemoryConsolidator 分离证据提交、索引和模型选择；LongTermMemoryAccess 为资料与注解工具共用的可信入口。替换 Store 时需实现 appendExplicit 的完整原文、附加信息、保护和幂等语义；默认未实现会明确失败。替换生成器仍需经过原处理器的学习/引用复核与事务端口证据校验，不以模型返回成功代替真实提交。IAgentDeliveryStore 可替换实际回执后端，继续遵守占用、逐段确认、未知不补发与有界清理契约。新模型适配和存储均在构造期不进行 I/O。

维护不迁移旧事实，不回收有效长期结论、无期限补正或不可变备份；原历史按自身保留策略维护。离线测试使用现有事务夹具；真实 MySQL 事务代理、锁、索引与真实模型摘要质量仍需实机验收。
