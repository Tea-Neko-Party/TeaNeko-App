# 自动上下文摘要

默认完整装配为已登记且启用的 scope 开启自动摘要，Agent 定义同时需要允许 SUMMARY 活动。摘要是会话压缩状态，独立于长期事实、UUID 画像、人格补正和持久化原文历史；不会因此自动新增个人事实。生成内容以低信任 USER 资料进入实际 Prompt，不能修改身份、工具或运行权限。

## 配置

```text
/cfg set agent autoSummaryEnabled false
```

本地默认值：

```properties
tea-neko.agent.summary.trigger-turns=12
tea-neko.agent.summary.keep-turns=4
tea-neko.agent.summary.trigger-bytes=32768
tea-neko.agent.summary.max-input-bytes=131072
tea-neko.agent.summary.max-characters=4000
tea-neko.agent.summary.max-model-calls=1
tea-neko.agent.summary.max-total-tokens=16384
tea-neko.agent.summary.timeout-seconds=45
tea-neko.agent.summary.cooldown-seconds=60
```

轮数或协议字节达到阈值后尝试生成，始终保留最近完整轮次；触发轮数须大于保留轮数。摘要默认独立最多一次模型请求且不开放工具，次数仍经过原 LLM 交互预算；总 token 使用原保守估算和供应商报告结算，不等同费用。输出 token 受原模型设置及 1024 上限共同约束，正文另受 max-characters 限制。后台超时最多五分钟，冷却最多一天；配置懒读取，非法值产生固定失败诊断，不阻断前台答案。

实际输入同时受完整协议字节和 token 预检约束；容量不足时仅选择更短的完整旧前缀，不截断轮次或工具往返。如果一个完整旧轮次也无法放入预算，则跳过本次生成。窗口容量、触发阈值、保留轮数及 token 预算需要配合；过小的窗口可能达不到阈值。

## 执行与采用

1. 原会话仍串行执行。只有通过原输入前缀、完整工具配对、最终候选及当前代次检查的成功轮次，才进入摘要候选。
2. 成功提交后在借用业务执行器尝试后台任务，前台不等待摘要模型。最多两个模型任务同时运行，没有模型等待队列；容量不足时由以后成功轮次再次尝试。同会话同一时刻只生成一次，并有独立冷却。
3. 后台将旧摘要和本次完整旧轮次作为数据交给原 ILLMInteractionService，复核真实 SUMMARY 准入、原空间和人格。保留来源、发言者及已观察工具结果，不执行数据中的命令，不将其当作思考过程或事实学习。
4. 生成成功后缓存覆盖的原 requestId/完整协议指纹及其继承摘要 ID。下一队首只有在代次、引用、人格、继承关系和当前窗口前缀全部匹配时，才一起采用摘要并移除对应原轮次。生成失败、超长正文或覆盖错位均不压缩原窗口。
5. 已采用摘要连同必要人格预留完整协议字节，普通记忆资料仍按完整片段省略。模型、工具、最终交付和缓存重放都复核本轮原摘要；正常窗口及原文历史不重复保存注入的摘要。

原窗口硬容量及输入限制仍有效。后台未及时完成而旧轮次已被原策略丢弃时，不会假装已覆盖缺失内容；后续摘要保留 partial 标志。已采用摘要自身超过输入预算时，明确返回 INPUT_TOO_LARGE，不悄悄删掉已替代原文的上下文。摘要可能省略具体细节，需要原文时仍可使用 history_query。

## 生命周期与扩展

摘要组件保存在当前 Conversation 实体中，后台缓存最多一千个会话、空闲三十分钟惰性淘汰，单份摘要有效期最多三十分钟，且不会超过其采用的人格补正有效期。它是可丢弃并由后续完整成功窗口重建的状态；重启不恢复旧窗口、摘要或未完成动作，持久化文本历史继续独立提供查询。

reset、clear、换记忆绑定或换人格会清除当前摘要组件；新的队首取消旧代次后台控制，迟到结果不能改投新会话。注销/禁用或关闭自动摘要后阻止后续使用和重放，已经压缩掉的旧轮次不会自动恢复。实例关闭、服务关闭及超时都会结束自身后台控制，不关闭借用执行器或模型服务。

IAgentConversationSummaries 分开 select、offer 和 verify：邮箱只管理不可变选择及纯数据提交，独立轮次只负责实际使用复核。自定义实现可以通过 AgentSummarySnapshot.create 构造有覆盖信息的状态，数据本身不代表授权。所有新旧构造方式保持显式能力组合，旧构造不会自动获得摘要功能。

每次实际后台交互通过 Usage 回调及最近一百条 reports 暴露独立执行 ID、原会话、实际终止状态、是否发布可用候选、预算维度及逐次 token 记账，保留 REPORTED/ESTIMATED 和未知差别，不保存 Prompt 或答案正文。默认日志只记录非敏感状态和预算；后续监控可复用同一观察口汇总前后台用量，观察失败不影响对话或摘要。

离线验证覆盖真实邮箱到模型、后台不阻塞前台、完整前缀压缩与实际 Prompt、重放、失败/超长降级、引用/人格切换、关闭、超时和资源回收。真实模型摘要质量、耗时与成本以及部署联调仍需实机验收。
