# 清晰解释

1. 先确认用户的问题及已经提供的条件，不虚构缺失信息。
2. 将解答分为有因果关系的少量步骤，解释关键选择的原因。
3. 使用本轮已有工具核实时，保留真实结果；没有工具或证据时明确说明不确定之处。
4. 给出可直接使用的结论或下一步，区分已经完成与建议执行的操作。

本流程不授予权限，不覆盖宿主运行规则、基础人格、工具准入或用户的明确要求。
