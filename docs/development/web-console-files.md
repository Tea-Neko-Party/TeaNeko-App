# 本地文件配置管理

控制台的“本地配置”按模块展示允许编辑的字段，模型另设[模型配置专页](web-console-models.md)。页面直接显示说明，无需展开。它编辑磁盘原始文档，不用已展开、已脱敏的对象覆盖文件。入口启用方式见[部署说明](web-console.md)。

v4.7.6-l 起，文件数据类型上的 `@Description` 作为完整用途说明直接显示；字段上的同一注解通过原格式解析器按实际 JSON 指针发现，支持嵌套、数组、泛型和别名，专用表单也可复用。说明只来自类型声明，不读取或导出原 YAML 注释及凭据；原有专用字段约束仍显示。维护者可在配置类或字段添加中文 `@Description`，不需要修改前端。

## 操作流程

1. 选择配置区，查看运行与磁盘是否一致及直接展示的文件、字段说明；高级模式额外显示版本与运行代次。
2. 普通字段直接编辑，恢复原文即取消该字段变更。高级模式可选择移除声明；秘密字段始终须明确选择替换或清除，原值不回显，也不会用星号写回。
3. 高级模式的“仅预检”检查原格式、环境变量和模块规则，不写文件、不发布缓存，也不调用远端模型。
4. “保存到磁盘”按原版本原子替换文件。完成后运行配置仍保留原值。
5. “应用磁盘配置”单独发布缓存并由模块确认。连接或固定资源需要重启时返回重启要求，不伪造热更新成功。

未修改的环境占位符和未知配置值保留；`${变量名}`、`${变量名:默认值}` 仍由原 YAML 解析器展开。**保存会重新排版 YAML，原注释不会保留。** 需要保留注释时在本机编辑，随后按原流程重载。

秘密字段只显示是否声明，不证明对应环境变量已提供或远端密钥有效。`metadata` 整体作为秘密字段处理，替换时填写完整 JSON 对象。移除声明恢复类型默认行为，不会从模板补回已删除的字段。

模型和人格列表支持新增、删除。一次保存只允许对同一列表做一次结构增删，不能同时修改其条目，避免索引变化修改错位。可同时修改列表外的字段；模型默认路由须与修改后的条目一致。

## 已开放的配置区

| 标识 | 内容 | 应用方式 |
| --- | --- | --- |
| agent.main | Agent 总开关 | 后续准入读取新值，模型就绪检查独立执行 |
| agent.models | 模型路由、参数、凭据、连接及 metadata | 后续构造请求使用新配置；不发起远端密钥测试 |
| agent.personality | 基础人格定义 | 后续会话按原人格身份规则换代 |
| agent.expression | 分段、等待、排队与发送超时 | 后续编译与准入读取新设置；在途发送保留原计划 |
| agent.stickers | 图库额度、限流、阈值、类别和排序权重 | 后续工作使用新设置，降低额度不立即删除文件 |
| agent.media | 选图限制、冷却和客户端表情映射 | 后续表达读取新设置 |
| onebot.main | 调试用户与启动状态 | 需要重启，不发布本次缓存 |
| core.runtime | 任务与日志的保留数量、保留时间及日志正文采集 | 后续观测读取新值，关闭采集不清除已有记录 |

其他非敏感 `@FileConfig` 可自动生成表单，标识为 `file.路径.文件名`（路径分隔符替换为点，不含扩展名），仍须逐项加入 `file-sections`。字段使用原解析器的实际键名，例如 YAML 的 `max-runs`；说明来自 `@Description`。专用适配器优先，敏感类型或含只写秘密的类型不自动开放。自动表单只校验原格式、环境变量及类型绑定，模块启动校验仍在重启时执行，因此默认返回 `RESTART_REQUIRED`。

需要热更新时由所属模块提供专用适配器。例如开放日志正文采集时，将 `core.runtime` 加入本地白名单，在“任务与日志观测”中修改 `capture-messages`，先保存再应用；后续日志按新设置采集。

认证根配置 `config/web/security.yml`、任意文件路径、图库物理目录和后端实现选择不通过网页编辑。只展示本地 `file-sections` 白名单内且所属插件已启用的区；修改此白名单后需按本机流程重载，原登录随安全配置代次失效。

模型文件发布后，已解析参数带有内部的非秘密配置代次。旧参数不能静默与新凭据混用；已同步构造的 HTTP 请求持有原凭据，继续遵循原超时与取消策略。网页应用不承诺撤销在途请求，也不修改每轮已捕获的输入。

## 回执与故障恢复

保存与应用各有独立操作 UUID。连接中断时保留原请求，通过“查询原操作”确认；没有记录或结果为 NOT_SAVED 时可以原样重试。修改参数后不得重用原编号。浏览器只在当前组件内存保留候选秘密，退出或刷新会丢失原请求，不写浏览器存储。

| 状态 | 含义 |
| --- | --- |
| SAVED | 已确认磁盘替换，尚未确认运行应用 |
| APPLIED | 本进程缓存发布及模块读取确认成功 |
| RESTART_REQUIRED | 文件保留，固定资源需要重启；没有发布本次缓存 |
| NOT_SAVED | 仍是原磁盘版本，可原样重试 |
| INDETERMINATE | 当前文件与原版本、拟替换版本都不一致，禁止自动覆盖 |
| APPLY_FAILED | 模块确认中断或失败，缓存可能已经发布，不能据此判断回滚 |

历史回执不证明当前进程或磁盘仍是同一状态。APPLY_FAILED、INDETERMINATE 先重新读取检查，再明确发起新操作。版本冲突不自动覆盖，页面可放弃草稿重新读取。

持久预写账本位于 `data/web/file-config-operations`，保留 24 小时，最多 256 项。文件与摘要密钥限制为服务账户可读写；不能建立权限或回执损坏时拒绝继续写入。账本只存带密钥的请求摘要、字段路径、版本和回执，不保存字段新旧值、秘密或环境展开值。不要单独删除摘要密钥来清理回执。

配置文件和账本不是跨文件事务。原子移动前登记拟替换的文件身份版本，恢复时比对真实文件，分别确认保存、未保存或无法确认。应用确认中断不自动重放模块钩子。

## 并发与限制

原 `reload`、`write` 和网页文档操作共享配置类型锁；旧缓存对象不能覆盖尚未应用的新磁盘版本。保存使用同目录私有暂存、强制写入和原子移动，不支持原子移动的文件系统会拒绝保存，不降级为先删后写。

单文件最多 1 MiB，单次最多 64 个字段动作，字段候选总量最多 262144 字符，同时最多 16 个实际文件工作。路径仅由注册类型提供，拒绝链接、越界和未注册类。版本包含文件身份、修改时间及正文摘要。

首期是单应用实例的协作写入；不能保证不遵守锁的外部编辑器在最后检查与移动之间也参与原子版本仲裁。保存期间避免同时在本机编辑，同一配置目录不要由多个应用实例共享写入。

实际文件与安全链测试使用临时目录及真实框架；页面另用离线 API 夹具检查。真实部署还须核验服务账户 ACL、目标文件系统的原子移动、环境变量、应用日志与实际模块行为。
