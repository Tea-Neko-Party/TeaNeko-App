# 三层自动记忆与观察式人格实施

版本：4.6.1-l，以当前 version.properties 为准。状态：开发中。当前规格以 [重设计文档](../design/agent-memory-personality.md) 为准；外部源码研究只保存在 temp/docs。

## 本次范围

- 短期消息及时持久化，按真实 client/scope、当前空间代次隔离，保留精确时间；重启后自动提供近期上下文。
- 中期片段持久化，后台自动压缩连续旧消息；提交和处理水位原子更新，作业可恢复。
- 中期自动筛选长期事实、偏好和经历；按 namespace 共享，支持时间精度、更新/冲突、纠正和遗忘。
- 自动用户画像及观察式表达学习，共用真实消息证据；按对象与场景选择，默认人格按 scope 独立。
- 复用专用 EasyData、LLM 交互、执行控制、注解工具和插件能力；提供可替换端口及必要诊断。

## 执行默认值

保留现有数据，不清库、不删除旧事实或人格。启用新流水线时保留现有显式保存入口；关闭学习开关不停止已经允许的短期采集。沿用已登记 scope 的原采集/读取权限，学习仅处理可验证的原作者发言。关系默认按 scope 独立；遗忘先排除派生记忆，不自动删除原始聊天；同一旧证据不得重新生成已遗忘条目。

## 本批交付及下一步

- 原历史事务同步保存短期消息、幂等来源和持久目录，重启后按同 scope 读取近期原文与中期片段，不依赖旧内存窗口。
- 后台有界扫描目录，按消息数或输入字节触发连续前缀压缩；租约、水位与片段持久化。关闭、策略撤销、绑定变化、空间 clear 和旧租约不能继续提交原候选。
- 中期事件范围来自原消息精确时间，普通注入使用概略月份，重要日期保留在摘要中；助手生成不表示平台已发送。
- 本批接通中期到长期的 LEARNING 模型选择和事务提交，自动画像直接投影有效用户事实；长期共享键只包含 namespace/generation。原话、作者、时间和租约核验后，记录、索引与处理水位原子提交。
- 默认能力接入自动画像/话题召回以及注解式 search、profile、correct、forget 工具；维护按本人真实身份、明确原文、原版本和固定调用 ID 提交。旧证据墓碑抑制重导入/改写复活，已更正或遗忘的旧投影不能继续用于模型。
- 新 scope 默认开启 memoryLearningEnabled；已有显式 false 保留，不重写现有配置。详细参数、工具及适用边界只维护在[模块说明](../../src/main/java/org/zexnocs/teanekoagent/memory/layered/README.md)。
- 本批完成观察式人格：同次 LEARNING 模型请求返回事实与表达两类候选；只观察属于原人格的真实用户原话，至少三条独立消息、两个片段才渐进采用，单批最多一项。观察、人格补正和整理水位同事务保存，保留原锁定、管理代次和 scope 隔离。
- 新增 personality_observations 注解工具查看当前 scope 的模式、场景、支持数量、作者及采用状态；不导出原话。默认装配开启观察时停止旧逐轮人格模型分析，关闭后保留兼容入口。详细规格只维护在[人格说明](../../src/main/java/org/zexnocs/teanekoagent/personality/README.md#持久观察式人格)。
- 本批完成到期与旧代次维护：短期/中期回收保留序号连续性，长期精简原话但保留事实、当前代次回执和遗忘保护；旧 generation 的正文、作业及索引逐页回收。人格层精简过期样本、保留无正文采用水位并释放到期补正容量，不修改不可变备份。
- Core 增加固定 namespace 的只读维护分页，Agent 表增加 namespace,id 索引；维护游标与每批变更同事务提交。调度独立于学习开关，支持替换维护端口、重启恢复、失败回滚、串行等待和关闭。
- 下一批统一显式记住入口与新长期领域，接通平台送达状态持久化并核对最终运行接入；现有原始聊天遗忘语义不改变。手工 DDL 环境需按专用 EasyData 文档补齐维护索引。
- 当前整体预估 93%，本批到期维护闭环及离线验证完成；显式入口统一和送达状态仍未完成。

## 验证重点
