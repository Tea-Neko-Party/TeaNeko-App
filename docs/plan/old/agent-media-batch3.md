# 第三批类别选图与独立发送记录

日期：2026/11/03。当前状态统一见[实施入口](agent-expression-stickers.md)；运行配置、工具与客户端扩展统一见[素材模块](../../../src/main/java/org/zexnocs/teanekoagent/sticker/README.md)，本页只保存交付与验收事实。

- 新增默认 media-replies 能力，显式依赖 expression；按真实 client/scope 提供类别与原生目录。没有实际保留资源资料时不安装目录工具，保持默认自主发言零工具合同。
- sticker_list 采用原注解注册与参数绑定；每轮最多两个类别、每类全部当前可用 ID/revision/描述。目录超出结果或已知输入预算时返回空项与 complete=false，不以截断内容冒充完整；可改选另一个完整类别。
- 资源资料、完整回执与单项计划绑定原请求、账号、配置及插件代次，模型不能凭历史或其他群提供的 ID 直接发送；签名不携带密钥或路径。只有本次真实成功且未截断的回执参与编译，普通历史移除整份临时目录。
- STICKER/FACE 注册为独立指令和有类型处理器，未知类型不增加中央 switch。图片以原图字节传输，OneBot 使用 base64，原生表情使用独立 face，均只可 plain/reply，不和文字或 at 混发。
- 通用注册入口独立执行原发送守卫，异步读取后再次复核。目录写锁取得文件占用，实际在途阶段结束后释放；取消观察不提前释放，缺失文件、条目换代、账号或开关变化不回退 URL、不换图。
- 实例最多八项图片传输持有原图及编码；容量等待在借用虚拟域响应取消，不持数据库锁。平台真实确认后才记录机器人展示及区域回避，不计人类热度。
- 按实际草稿序号冻结缺省等待，避免异步解析尚未填充步骤时把后续段当作首段。可替换客户端编码通过接口、注解、Bean、scanner 与插件代次组合；未知 client 不推测能力。

离线验证复用原数据库事务、FakeClient 和真实 OneBot 编码器，仅新增四项核心用例：

- 完整注解目录、冻结协议、文字/图片/原生表情独立发送、真实逐段账本、确认重放不补发及跨区域共享/回避。
- 未查询、截断、改写或跨请求目录拒绝；素材版本/文件变化不产生实际发送，失败释放占用，普通历史不沉积控制与整份签名目录。
- 八项实际在途持有文件，第九项等待可取消；已开始发送取消后保持占用，实际确认后才计数和释放，回收不删除被占用文件。
- 完整类别预算、失败类别后改选有效类别、两类别上限、独立方式与原生开关失效。

集中回归 112 个测试类、1027 项用例：1026 项通过、1 项真实模型按原设置跳过。最后发送容量/可空回避计数修正执行相关用例并强制重建两个 JAR，计数不与集中回归相加。中文 JavaDoc、当前产物逐字节、三个表达/素材模板、metadata、文档链接、参考名称隔离与差异格式集中核对；详细摘要和日志位于 build/tmp/media-replies。

最终定向四项通过；两个 4.6.1-l JAR 各含 1490 个生产类并逐字节匹配编译目录，23 项 metadata、原生访问声明及 expression/stickers/media-replies 三个模板一致。工作区相关 100 个 Java 文件、903 项显式声明通过中文 JavaDoc 审计，完整生成退出码为零；文档链接、名称隔离和 git diff --check 通过。regression-final.log 保存集中回归，final-build.log 保存最终定向和强制构建，delivery-summary.json 汇总交付核对。
