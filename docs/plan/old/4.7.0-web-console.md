## 当前边界

默认关闭公网 Web 控制面；启用必须设置合法 HTTPS 外部来源，机器 WebSocket 入口需单独凭据。未配置管理员令牌时本次启动生成随机值，配置损坏拒绝开启，不退化匿名。登录根令牌不进入普通日志或前端持久存储。

单实例首期不承诺多 Web 副本共享会话。OneBot 的连接数不等于账号路由就绪，未完成身份/定向路由前不开放跨 client 指令。记忆保持原默认共享规则，界面映射不擅自改动实际 scope 编码。

不启动真实机器人、模型或 MySQL，不发送真实消息。仅验证必要安全边界、核心流程和实际构建产物；实机 HTTPS、代理、机器凭据及公网检查另列部署验收。
