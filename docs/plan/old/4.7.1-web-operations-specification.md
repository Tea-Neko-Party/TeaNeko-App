# v4.7.1-l Web 管理补丁规格

本文件保留已实现的功能与接口边界；完成状态见[实施记录](4.7.1-web-operations.md)。

## 1. 机器令牌及启动诊断

- `machine-tokens` 独立于管理员登录凭据：允许 0～256 字符，非空短令牌合法；空字符串或纯空白字符串归一化为无需验证机器令牌。
- 明确配置 `onebot: ''` 时，该客户端允许任意令牌及缺省 Authorization；完全省略该客户端时继续拒绝。页面须明确展示“任意令牌可连接”，不能把未配置和空令牌混为一谈。
- 非空机器令牌不得包含空白，管理员令牌继续遵守原长度与认证规则。机器令牌与管理员令牌不混用；机器令牌放行不改变 HTTPS/WSS、管理会话和 CSRF 校验。
- 网页提供客户端列表、令牌配置状态、主动显示/隐藏、修改、清空和应用。只向已认证管理员的专用接口返回其明确查看的令牌，不将整份安全配置作为普通文件导出。
- 读写接口声明禁止缓存；秘密不放进 URL、审计正文、错误链或网页日志。操作回执只含客户端、状态和版本，不含令牌。
- 保存经现有文件配置类型锁、原文档局部编辑和原子替换完成，保留其他字段及未修改的环境占位符。使用原磁盘版本检测并发修改；应用与保存结果分别表示。
- 页面保存前说明 YAML 重排和注释可能丢失。沿用安全配置变化的会话撤销策略，并明确提示可能需要重新登录；不能将应用后的会话失效误判为“未保存”。
- 令牌换代后，对应机器连接的后续收发继续复核，客户端重新连接时使用新策略。
- 启动错误分别报告配置校验、根凭据准备/文件写入、提示读取阶段和安全的原因编号；不再把所有失败仅合并成一句“文件不可用”。不得输出含秘密的解析原文或任意异常消息。

## 2. HTTP、HTTPS 与原生库提示

- `server.port` 默认 6691，提供后端 HTTP/WebSocket；前端开发端口默认 5173，提供 Vite HTTPS/WSS。沿用已完成的统一端口配置和代理派生。
- 本地 OneBot 连接 Vite 的 `/ws/onebot`，经代理到后端；生产连接正式 HTTPS/WSS 代理入口。机器客户端须自行信任开发证书。
- `wss://` 直接连接普通 HTTP 后端，会出现 TLS 版本错误及 HTTP 方法含 `0x16 0x03` 的解析错误。实施时核对真实连接入口与代理链，不用关闭安全过滤器或隐藏 Tomcat 日志掩盖端口错误。
- 本补丁不要求同一普通 HTTP 监听端口同时识别 TLS；若部署采用后端直接 TLS，另按 Spring SSL 配置其证书和监听方式。
- JDK 原生访问授权属于应用 JVM 启动配置。核对 `bootRun` 和 JAR Manifest 的既有授权，并在可复用的 IntelliJ 启动说明中给出 VM 参数，不把依赖警告误认成记忆或模型失败。

## 3. 分层记忆诊断

- “中期片段/长期候选未提交”表示一次后台生成、校验或提交没有完成，原输入和整理进度保留后退避重试；两条旧警告不足以确定是模型、输入格式、预算、资格、租约还是存储问题。
- 沿用当前重试、预算和幂等提交，不为了去掉警告而推进水位、删除原消息或保存虚假结果。
- 增加可区分的处理阶段、模型结果状态、异常类型、代码位置及可关联的任务标识；对已知原因给出简短中文诊断。
- 不在失败日志中输出原对话、模型原文、凭据、完整提示或可能携带这些内容的异常链。
- 网页日志可筛选上述原因和处理域，说明哪些失败可自动重试，哪些需要修改配置；保留真实失败事实。

## 4. 通用配置与聊天区域登记

- 自动发现项目中已注册、启用的 `@ConfigManager`，复用其 `configType`、命名空间、专用存储和 `fieldChecker`，不要求每增加一个普通配置都手写 Web 适配器。
- 专用适配器可以覆盖通用投影，例如 Agent 记忆绑定保留专用管理入口；发现键冲突时明确报告。
- 配置名称与用途优先使用 `@ConfigManager.description`；类型、字段的 `@Description` 提供中文标签、说明和限制，缺失时显示真实字段名及“尚未提供说明”，不编造含义。
- 根据字段类型生成布尔、数字、文本、枚举和集合/对象 JSON 编辑器；泛型、继承字段及序列化别名按实际 DTO 契约解析，禁止原始类型和未经检查的转换。敏感字段经专用交互处理，不从通用序列化泄漏。
- 操作路径仍按平台、机器人账号、群聊/私聊、实际目标定位。网页不允许任意输入内部数据库键来绕过真实目标解析。
- 客户端适配器声明目标适用的配置命名空间；服务端在读取、登记和修改前复核，不能把只支持某平台/群聊的规则注册到其他目标。
- 支持为选定聊天区域登记一个尚未存在的配置、预览类型默认值、修改、注销和查询回执。复用现有原子事务、原字段校验、缓存失效和幂等操作编号。
- 登记文案按真实配置类型显示，不能所有配置都称为“登记并启用 Agent”；注销配置不删除聊天、历史、记忆或其他配置。
- 页面将“Agent 配置”和“其他功能配置”分开，平台账号与聊天选择可复用，各配置独立保存草稿、登记状态和版本，切换时提示未保存内容。
- 开放策略支持配置分组及已注册配置目录，不靠逐项增加中央分支；沿用本地授权声明，并在升级说明中列出需要开启的分组，不能发现新配置后静默绕过授权。
- 本地 `@FileConfig` 配置继续经原文件编辑能力管理，与聊天区域配置明确区分。扩展可展示、可编辑的注册配置，复杂或敏感文件允许专用适配器；管理员令牌和 HTTPS 信任根不作为普通配置开放。

## 5. 定时任务展示和分类

- 新增用于类或方法的声明式展示注解，包含稳定分类标识、中文分类名、名称、说明及展示意图。普通 DTO 不增加无用注册层。
- Core Timer 从已有方法引用/任务来源读取注解；无法推断来源时允许注册端显式传入展示元数据，不依据任务名称字符串猜分类。
- Spring `@Scheduled` 任务通过其实际注册任务与方法关联展示，不复制一套调度器。Core 与 Spring 记录统一为只读管理视图，保留各自执行机制。
- 未提供元数据的旧插件任务保留兼容行为，归到“未分类”；不可控制的任务明确显示只读，不提供虚假的暂停、恢复或取消。
- 分类建议：Core 维护、Agent 记忆、Agent 主动活动、Agent 计划任务、客户端维护、业务插件、未分类。具体条目实施前根据实际任务清单核对，注解中声明分类，不加入中央名称匹配表。
- 对当前缓存清理、系统监测、签到、活跃管理、群请求清理、头衔维护、点赞、Agent 候选/持久计划及已注册记忆维护任务逐项分类。
- 网页可点击分类标签/筛选器，支持分类、规则类型、运行状态、名称和分页；过滤须在服务端分页之前执行，切换筛选重置游标。
- 调度循环、关键数据库清理和其他缺少安全控制能力的任务不因页面新增就自动获得停用入口。现有可管理 Timer 继续使用真实版本门禁与操作回执。

## 6. 机器状态和实际版本

- 提供独立采样接口，显示系统 CPU、当前进程 CPU、JVM 堆/非堆已用量、物理内存已用/总量、处理器数、运行时长和采样时间。
- “JVM 已用内存”“堆上限”“系统内存”“进程常驻内存”分别标注；不能把已提交虚拟地址空间或堆上限冒充进程实际物理占用。底层无法提供的指标明确显示不可用。
- 采样与平台插件解耦，优先复用已有系统状态能力；CPU 第一帧或系统不支持的值不能伪装成零。
- 当前页面可见时按有界间隔刷新，页面隐藏、退出登录、切换页面或组件销毁时暂停/取消，不重叠请求，不长期堆积完整采样历史。
- 版本只读取真实构建产物信息。修正 IntelliJ 或普通 classpath 启动仅显示 `dev` 的情况，必要时在构建资源中提供来自 `version.properties` 的版本信息；不建立第二个手工维护的版本号。
- 实际程序升级、回退、远程下载、安装包执行及重启切换均暂不实施。

## 7. 验证与交付

- 必要回归：空/短/无令牌与未配置客户端、管理员认证隔离、未登录和无 CSRF 的写入拒绝、并发文件/配置修改、命名空间约束、登记幂等及任务分页过滤。
- 机器状态验证口径和不支持指标；记忆失败验证原输入/水位保留及脱敏诊断，不连接真实模型。
- 界面验证与响应式要求见[界面方案](4.7.1-web-interface.md)。复用既有夹具，不为简单展示对象堆叠测试。
- 运行相关测试和前端类型/生产构建，核对隔离编译结果、实际 JAR 中的类、版本资源和静态文件。README 和补丁日志按最终行为同步。
