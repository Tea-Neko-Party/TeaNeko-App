本次新增完整管理闭环：

- 四项真实 ManagementResource：图库/作业/容量分页、受控 PNG 预览、版本管理写入及本人原操作回执。沿用原网关和显式 ManagementAuthority，缺失授权默认拒绝，要求 global 范围；不新增 HTTP、页面或聊天权限提升。
- 固定、停用、启用、删除墓碑、显式恢复、类别/描述修正与后台刷新均接通。条目版本仲裁、幂等请求与回执在同一专用 EasyData DTO 事务提交，回执保留 24 小时、最多 512 项；同请求重放不再次通知。
- 删除先撤销选择，再等待发送、预览或刷新占用后回收字节；墓碑阻止同图聊天自动复活。人工停用同样不能被普通采集重新启用。分析与实际回收同时推进公开版本，旧管理请求明确冲突。
- 刷新复用原文件、持久队列、SYSTEM 视觉活动和原额度，不重新下载旧 URL、不增加人类热度。原停用项完成仍停用；迟到结果不能覆盖人工修正。预览/刷新在物理任务结束后释放文件占用，文件 I/O 和模型请求不进入根事务。
- StickerCollectingEvent 只允许同步拒绝和低信任提示，真实来源不可替换，取消单向生效，完成/失败/超时冻结。StickerCommittedEvent 在真实提交后只读通知；原 Core scanner、事件服务与插件归属继续生效，event-plugins 明确选择第三方参与。
- 决策五秒超时、事件合计 64 项在途、预览两项并发；通知拥塞或失败不回滚真实业务，通知不冒充可靠审计或浏览器推送。管理、事件、后端与客户端开发说明及部署验收清单已同步。

仅新增三项必要核心集成测试，复用已有真实 DTO、文件、队列和 FakeClient 夹具；事件经过实际 Core scanner、EventService 和 PluginAccess，仅省略测试调度和模型网络。覆盖默认拒绝、撤权、全局范围、预览释放、版本冲突、幂等、写失败回滚、删除占用/墓碑/恢复、受限事件冻结，以及刷新与人工修改仲裁。
