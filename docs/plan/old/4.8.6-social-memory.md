## 边界与决定

新增社交能力通过 ECS 独立装配，不改变仅 LLM 的初始 Agent。心情影响虚构角色的表达，不能绕过主动发言权限，也不持续追问用户。跨 scope 资料保留来源；以真实用户身份关联，私聊内容不因群聊里出现同一用户就自动向群内公开。

记忆空间选择使用持久目录；创建空间仍由专门管理动作完成。新增共享上下文和私聊能力应当有可关闭的组件参数，不通过模型填入目标标识绕过实际目标校验。

调查及逐项验证记录放在 `temp/docs/4.8.6-l/social-memory/`；完整离线日志在 `temp/verification/4.8.6-l/social-memory/`。不调用真实模型，不发送真实平台消息。
