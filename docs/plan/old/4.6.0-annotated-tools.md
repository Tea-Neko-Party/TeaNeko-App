# Agent 注解工具开发与迁移

版本：4.6.0-l。目标：普通 Spring Bean 只需类标记和方法标记即可向 Agent 贡献工具，不要求开发者手写 schema、工具绑定或实现工具接口。

## 当前规格

- `@TeaNekoAgentToolClass` 标记已注册的 Spring 服务/组件；类可设置所属插件、能力 ID、工具包和默认安装策略。默认归属 Agent 宿主，普通新工具无须再编写 AgentFeature。
- `@TeaNekoAgentTool` 标记公开实例业务方法，默认方法名为工具名；支持 client 白名单，未指定则所有 client 可用。`@Description` 描述方法和参数。
- 参数复用既有 schema 工厂；支持可空参数、枚举、集合、UUID、DTO，复用 `@DefaultValue`；补充参数重命名和 DTO 根参数展开注解。宿主上下文与原工具调用不进入模型 schema。
- 支持同步返回值、CompletionStage、纯 DTO 和显式 LLMToolOutput 图像结果；使用 Spring 代理调用方法，保留原异步完成、取消、权限、客户端和插件版本守卫。
- 复杂工具可通过方法条件检查当前请求是否可见，选择及实际执行前后复核。动态业务仍由原领域服务检查，不用注解替代授权。
- 自动发现时只读取 Bean 类型元数据，延迟获取业务 Bean，避免扫描造成构造循环。既有能力通过 managedByFeature 明确拥有工具，不重复装配；普通自动能力与既有能力重名时报错。独立宿主与测试保留显式选择入口，入口改用同一注解编译器。
- 迁移主要常用工具：记忆三项、历史查询、命令执行、OneBot 三项、用户资料两项，共十项。动态后端扩展和依赖实际 Prompt 目录的 Skill 保留底层绑定入口，避免为统一形式放宽其准入。
