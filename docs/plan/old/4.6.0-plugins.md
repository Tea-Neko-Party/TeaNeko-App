# 4.6.0 插件化实施入口

版本：v4.6.0-l。状态：本次插件化范围代码、文档和离线验收完成 100%。开始或压缩上下文后先读 AGENTS.md、本文件，再按需读 [插件开发入口](../../development/plugins/README.md) 与相关实现。

## 交付范围

按 [插件设计](../../design/agent-plugin-extensibility.md) 与 [管理接口设计](../../design/web-management-api.md) 实现受信任、随应用装配的 Java 插件：Core 注册/依赖/逻辑启停、命令/事件/任务阶段归属、类型化异步拦截；Agent 能力选择、工具/资料聚合、受控组件/System、决策及观测事件、任务动作；管理能力描述与结构化查询入口；按 Core、Agent 和管理职责拆分编写指南与可编译示例。

复用 TaskStageChain 单线程调用栈，允许其启动异步业务，业务完成由返回 Stage 表达。Agent 原准入、来源、预算、版本和副作用守卫保持生效。Agent 数据仍经专用 EasyData。插件逻辑禁用不等于卸载 Spring Bean、自动撤销副作用或恶意代码隔离。

本次不交付动态 JAR 上传/类卸载或完整 Web 前端；管理合同为未来 Web 复用，已实现项与后续适配分开记录。版本文件同步为 4.6.0-l，不自动提交、打标签或推送。

## 验收与实际边界

- 100 个离线测试类共 974 项：973 通过、1 项真实模型测试跳过。沿用原 98 类集合，新增两类共 12 项，覆盖目录/依赖、真实 Spring 启动禁用、命令完成版本、管理授权、环绕等待/防重、真实 Agent 组件/工具/事件闭环、禁用再启用、异步决策拒绝和交互后 STOP 拒绝交付。
- 强制重编译并构建普通与可执行 JAR；当前 1296 个生产类在两种产物中均与编译目录逐字节一致，配置 metadata 含插件配置项。58 个相关 Java 文件的 87 个类型、411 个方法完成中文 JavaDoc/参数/返回/异常检查，原生 JavaDoc 通过。未实质修改的嵌套类型保留自身旧实现版本。
- 修复完整测试首次暴露的内部客户端惰性代理对 final 具体类型的限制，改为明确限定的接口注入；未以此宣称完整应用、真实 MySQL、OneBot 或外部模型已启动验收。实机测试继续按原部署清单执行，未主动触发平台消息或外部模型。
- 管理入口目前提供插件目录及 Agent 实例两个只读资源，缺少可信授权实现时全部拒绝；记忆、群配置、任务/Timer、日志与实时流仍按管理设计逐项适配，未发布 HTTP 或页面。
- 外部插件通过依赖与显式 Spring 装配接入，逻辑启停不销毁 Bean 或自动回滚副作用；动态 JAR 上传/卸载、独立 Maven SDK 发布及不可信代码隔离为后续范围。
- 证据与日志位于 build/tmp/plugins：verification.log、review.json、inventory.json、javadoc-final.log 和回归类清单；临时目录不纳入版本库，缺失时按清单重建验证。未执行 Git 提交、标签或推送，旧 JAR 保留。
