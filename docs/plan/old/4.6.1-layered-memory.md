## 执行默认值与边界

保留现有数据，不清库、不删除旧事实或人格。启用新流水线时保留现有显式保存入口；关闭学习开关不停止已经允许的短期采集。沿用已登记 scope 的原采集/读取权限，学习仅处理可验证的原作者发言。关系默认按 scope 独立；遗忘先排除派生记忆，不自动删除原始聊天；同一旧证据不得重新生成已遗忘条目。

新 scope 的 memoryLearningEnabled 默认 true，已有显式 false 保留。首期不强制向量库、图数据库、独立模型循环或完整 Web 页面；旧事实不自动迁移，平台未知发送不补发。规格中的长期演进建议与历史待确认项不作为本次已经上线的功能。

## 本次收尾（2026/11/03）

- 真实原文“记住/请记住”支持可选冒号；模型前等待保存，不依赖自动学习、历史采集或模型恰好调用工具。原动作、正文、附加信息及去重同事务提交，保留人工保护和有效期。
- 命令、自动回复和自主发言接入独立送达账本。有效平台消息 ID 才确认，部分发送只投影已确认正文，未知结果和重启都不盲目重发；后台摘要区分生成与平台确认。
- 原生上下文补充真实 selfPlatformId 和 mentionedSelf，明确“@ 当前机器人”，不再依赖账号是否具有 TeaNeko UUID；不改写用户原文或新增授权。
