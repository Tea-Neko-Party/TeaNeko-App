# Agent 平台上下文与共享记忆修正

版本：4.6.0-l。六项需求的实现和离线验证已完成，完成比例 100%；真实 OneBot 与模型验收仍按部署环境执行。

## 当前规格

1. 已登记并启用的私聊普通图文直接触发被动回复，保留命令排除、自身消息排除和原准入。
2. Agent 各子命令添加中文 `@Description`，由现有 subhelp 读取。
3. 事实与画像按 namespace/generation 共享，不按 scope 分区；未切换的所有 scope 使用同一 default。人格默认补正键继续按 client/scope 隔离。修正过窄的自动召回，保留显式关键词工具查询。
4. 工具可声明 client ID 白名单，空集合允许全部 client；选择和实际执行均受约束，插件包装保留限制。
5. 提供 OneBot 消息 ID 查询、发送者/引用消息发送者信息和当前群信息工具，包含昵称、群名片、头像地址、群名称；身份来自宿主来源，消息读取核对当前 scope，不向模型开放任意跨 scope 读取。
6. 用户确认：身份与 scope 仅作为送给模型的上下文，不在聊天窗口显示。上下文与原文分离，保留 TeaNeko UUID、平台用户 ID、client/scope、消息 ID、昵称、群名片及可用群资料；显示字段不是授权依据。
