## 边界与入口

保持 Core → App → Agent → Client → Plugin。模型适配留在 Agent，官方客户端留在 Client；业务插件按 agent、general、onebot、web 分类。插件随应用装配，全部迁出的内置业务支持可重复热启停；保留历史数据并自动迁移配置。独立页面随 Vue 构建，不实现动态 JAR 装卸、市场、软件更新器或部署容器。

需求与已确认答复见 [需求规格](4.9.0-plugin-requirements.md)。参考研究仅在 temp 内保存。本次[验证记录](../../review/4.9.0-l/verification.md)与[真实环境验收](../../review/4.9.0-l/next-steps.md)独立维护，不将历史证据算成本次结果。
