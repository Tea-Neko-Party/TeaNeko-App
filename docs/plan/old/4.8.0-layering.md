# v4.8.0-l 分层与组件目录重构

状态：已完成，100%。完成日期：2026/11/05。版本仍为 v4.8.0-l，保留既有装配、协议、数据库键与公开操作行为。

## 本次范围

1. 修复 Core/App/Agent/Client/Plugin 的倒置依赖，平台适配归客户端，通用管理错误处理通过下层契约扩展。
2. 将记忆、人格、模型、表达、表情、技能、工具、调度等完整能力实现归入 `component/<能力>`；运行生命周期归 `runtime`，App 集成归 `integration`，共享数据基础设施独立保留。
3. 内部 `teaneko-agent` 客户端保留现有 Sender/Response 契约，整体迁到 Client 层；不再保留 `agent/client`。
4. 拆分多工具类，保留工具标识、Prompt 所有权与调用条件，解除工具组件对 OneBot 的固定依赖。
5. 更新引用、模块文档及日志，执行分层检查、必要回归、强制编译和产物核对后归档。

## 执行边界

- Core 仅自身；App 仅 App/Core；Agent 仅 Agent/App/Core；Client 可依赖自身及前三层；Plugin 位于最上层。
- Agent 中仅依赖 App 通用消息契约的集成仍属于第三层；具体 OneBot/Web 实现由各客户端主动提供。共享客户端实现位于 `client/general`。
- 包迁移同步生产与测试引用；保留类创建日期、首次版本、Bean 名、HTTP 路由、事件/工具/配置及持久标识，不回写或迁移真实数据。
- 不修改用户的 `gradle.properties`，不启动真实服务、模型或数据库，不提交 Git。

## 已交付

- 五层生产源码依赖检查通过；App 管理错误通过声明式端口映射，不引用 Agent 异常或 Client 控制器。
- 各能力完整归入 `component`，运行域归 `runtime`，App 通用接入归 `integration`；模型配置装配统一归 `component/llm/configuration`。
- OneBot/Web 主动贡献平台工具与表达适配，共享素材发送在 `client/general`；内部客户端整体迁到 `teanekoclient/agent`，保留原 Sender/Response 合同。
- 所有注解工具提供者均为单工具类，共享业务服务复用；平台能力通过组件要求主动装配，不在工具组件硬编码客户端。原生表情目录的缺省与显式空表仍分别表示使用平台默认和禁用。
- 规范、开发指南、模块入口与发布日志同步更新。旧 Java 包不保留转发壳，外部插件须更新 import 后重新编译。
