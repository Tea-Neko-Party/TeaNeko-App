## 运行合同

- Core 只提供中立插件元数据、依赖及代次门禁；App 解析客户端要求。客户端提供者形成依赖边，暂时离线不改变插件状态。
- 模型、运行生命周期、权限、预算、取消、组合、工具框架、通用交付与防重留 Agent。业务服务、Store、配置、工具、任务和管理资源整体随插件迁移，禁止下层反向引用实现。
- 认知保留联合事务；跨聊天读取不再反向依赖社交实现。Agent EasyData 根入口及实体不改表，业务经原入口与 DTO 访问。
- 重名和环明确拒绝；普通插件缺失依赖进入可诊断阻塞。扫描只发生在初始化或显式重扫，完整结果原子发布。
- plugins.yml 保存期望状态，首次导入旧禁用列表，此后不让旧配置覆盖管理操作。文件保存与真实启动分开报告。
- 管理页预览受影响项，版本匹配后持久意愿并按拓扑协调；依赖方保留原意愿。失败保持门禁关闭，允许显式重试。
- 热停先撤销新调用，再停调度、取消自有工作并等待真实结束；重新启用生成新代次，不复用已关闭资源、不补发过期单次任务。已提交副作用保留真实回执。
- 重启型插件以真实状态展示待重启；内置业务全部热启停，不显示重启提示。

## Web 与升级合同

- 插件总管理属于不可停用宿主。组件、System、工具、命令、配置区、任务和页面均显示 pluginId 并可筛选。
- IPluginConsoleContribution 配合构建期 Vue 模块自动生成插件配置二级菜单，复用原主题、草稿、轮询和授权合同。
- 有效停用后除总管理外全部相关功能隐藏；已挂载页、弹窗和轮询失效，迟到结果不能重新挂载。后端直接调用同样拒绝。
- 保存的装配保留全部原意愿，运行投影只含有效能力；普通页面按可编辑字段合并，不能删掉隐藏参数或秘密。
- memory 合并 shared-memory，新增 crossChatRecallEnabled，仅继承原显式开启状态；人格仍可独立装配。冲突不覆盖原行。
- tool.commandToolsEnabled=true 转为 automation 的 command 组件，依赖 tool；原 false 不增加权限。迁移 Feature ID、配置引用及精确白名单，不扩大授权。
- 保持表、namespace、客户端 ID、存储键及既有配置路径。Java 包变更允许接入方重新编译。
