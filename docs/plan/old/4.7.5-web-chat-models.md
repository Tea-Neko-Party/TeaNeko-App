# v4.7.5-l 聊天室与模型配置

状态：约定功能与离线验收完成，整体 100%；尚未确认发布。

## 实施顺序

1. 网页回复链路：修复实际子事件的继承监听；网页私聊缺少配置时原子登记并启用 Agent，保留已有关闭决定；原异步业务结果可查询。
2. 房间式聊天：先选择私聊或群聊，进入以对话为主的聊天室；上方切换聊天、会话设置、成员及图片，支持返回目录；引用展示作者与摘要，原消息/引用 ID 只在高级模式显示。
3. 指令服务：复用原命令注册、插件、客户端、权限与 scope 检查；聊天室 `/` 和子指令补全，独立指令一览展示详细说明、参数和适用条件，不因查看而获得执行权限。
4. 文件与模型页面：普通文件说明直接展开；模型单独导航，按路由分卡编辑；复用原版本化文件保存、回执和独立应用，保留原环境模板与未修改秘密。
5. 模型扩展：供应商目录中贡献注解式 Spring 配置适配器，发现实际注册模型后提供默认地址/路径和样板；支持自定义模型参数及连接；API key 提供手动、环境变量和可扩展输入方式。
6. 集中验证、更新文档与发布日志、构建产物核对，完成后归档。

## 边界与决定

- 默认启用仅针对网页私聊且配置尚未登记；群聊、已有显式关闭和本地总开关继续执行原规则。初始化通过 Agent 专用 EasyData 及原配置事务，禁止直接访问 Repository。
- 页面管理员身份与网页发言成员权限分开，补全使用所选真实成员；指令一览可展示实际目录和条件，执行仍由原分发器复核。
- 房间切换、返回与页面切换继续保护未保存草稿及未确认操作。后台增量读取不锁输入，不自动重发消息或命令。
- 模型模板仅提供注册适配器的样板，不探测远端或伪造可用性。供应商固定参数来自本适配器及已核实资料，具体模型与真实上下文容量可编辑。
- 凭据不导出原值或写入浏览器存储，输入方式生成原文件可解析的值；保存和应用保持独立。自定义连接使用现有注册协议适配器，不动态加载 Java 类型。
- 当前版本通过既有 Gradle 补丁入口升级，不提交 Git、不打标签或部署。
