# v4.7.1-l 控制台界面方案

完成范围见[实施记录](4.7.1-web-operations.md)，数据与权限边界见[补丁规格](4.7.1-web-operations-specification.md)。

## 方向

学习参考界面的信息分区、卡片密度、导航反馈和主题组织，独立设计 TeaNeko 的布局与样式。保持 Vue、TypeScript、Element Plus，不迁移框架，不复制页面、品牌图标、素材或业务文案。具体来源及对照记录仅保存在 `temp/`。

浅色工作区背景固定使用用户指定的 `#F5F3ED`，搭配暖白卡片、低对比边框、统一圆角和轻阴影；保留茶绿品牌色。深色主题使用独立的语义色变量，不逐页堆叠覆盖规则。减少装饰和长说明，让状态、操作与结果易于区分。

设计与实现时允许按需重新阅读 `temp/` 中的界面资料，确认布局、登录和操作反馈；来源名称、路径和比较记录继续只保存在 `temp/`。不以一次调研替代实际页面核对。

## 简洁与高级模式

- 默认使用简洁模式，提供明确的“简洁 / 高级”切换；这是信息密度选择，不改变权限、请求参数、校验或业务能力。偏好仅保存到当前浏览器。
- 简洁模式优先显示当前状态、常用字段和一个主要操作。减少常驻输入框、重复刷新按钮、技术编号、长说明和无用途的禁用控件；详细内容通过“更多筛选”“使用说明”“详细信息”等局部展开入口查看。
- 高级模式展开诊断条件、字段来源、默认值、操作编号和较少使用的编辑选项。切回简洁模式保留草稿、选项和筛选值；高级筛选生效时仍有可见提示，不能让用户误以为没有筛选。
- 错误、待确认提交、实际副作用、保存与应用的区别、未保存修改及必要确认不受模式隐藏。每个页面只保留当前操作所需的短提示，不逐页重复权限和实现说明。
- 聊天设置的常用 Agent 字段先展示，其他字段有明确展开入口；其他配置按真实元数据决定展示，不能因为不认识字段就隐藏必填内容。
- 本地配置的普通字段直接编辑，原值不变时不产生写入；移除声明等特殊编辑方式在高级模式显示。秘密字段继续明确选择保持、替换或移除，不把空输入隐式当作清空。
- 日志默认只显示等级与正文搜索；来源、请求号、聊天标识、插件及时间区间按需展开。网页聊天优先展示消息与发送区，档案、角色和媒体管理留在各自分区。

## 登录页

- 使用居中、窄宽度的单卡片，不再设置宣传区、长标语和双栏介绍。首页只显示 TeaNeko 标识、令牌输入、可选保存和一个登录按钮。
- “令牌在哪里”放入可展开帮助，错误直接显示在表单内；主题切换保持轻量，不把高级模式、连接参数或未来认证方式加入登录表单。
- 保留链接令牌优先填入、及时清理 URL、成功认证后自选保存、取消保存后清除、Enter 提交及请求中禁用重复提交。只改变呈现，不增加自动提交或变更认证协议。

## 信息架构

| 导航分组 | 页面与主要内容 |
| --- | --- |
| 概览 | 实际版本、CPU/内存卡片、客户端连接、最近状态 |
| 客户端 | 平台与账号、连接状态、机器令牌查看和编辑 |
| 聊天配置 | 共用平台/聊天选择，Agent 配置与其他功能配置分别管理 |
| Agent | 活动时间线、记忆、人格、画像、计划及既有专用操作 |
| 本地配置 | 文件区分类、说明、保存/应用状态与回执 |
| 任务与日志 | 定时任务分类、实际运行、筛选日志 |
| 聊天与指令 | 网页聊天、客户端指令台 |
| 会话 | 当前登录、主题、退出登录 |

不将暂不支持的操作做成可点击入口。原始内部标识只在定位或诊断确有需要时展示，常规页面优先显示中文名称和业务状态。

## 布局和交互

- 桌面采用可折叠侧栏、紧凑顶栏、面包屑和有宽度约束的内容区；移动端使用抽屉导航，内容不会被侧栏挤出视口。
- 概览用少量卡片呈现系统状态、进程状态和客户端状态，图表只承载有意义的趋势，不将静态值包装成无数据图表。
- 表单按职责分组，说明贴近字段；修改、保存到磁盘、应用到运行时、重新连接和重新登录分别反馈。
- 定时任务页先选分类，再筛选状态和规则；卡片/表格密度随屏幕调整，名称、下一次触发和可用操作优先展示。
- 配置页展示当前值、默认值、字段说明、来源和独立登记状态；复杂 JSON 提供格式错误位置，不能只返回泛化的“保存失败”。
- 机器令牌默认遮挡，主动显示后可复制；空白放行显示清楚的状态标签。秘密不进入非必要的浏览器持久存储。
- 登录页保留快捷填入和自选保存令牌；已认证页面的空状态、失败、处理中及部分成功样式统一。
- 浅色/深色主题支持系统偏好与手动选择；偏好可本地保存，控件、提示、日志、代码区均保持可读。
- 抽取导航、状态卡、筛选条、配置字段和操作回执等真正复用的组件；领域组件保留各自数据与业务契约，不把所有逻辑搬入一个中央页面。
- 不因视觉改造丢失草稿保护、分页、滚动位置、筛选条件、权限提示或退出时清理请求的行为。

## 验收

- 检查桌面、窄屏和移动端；侧栏折叠、键盘焦点、表单标签及主题切换可用。
- 截图核对登录、概览、机器令牌、两类聊天配置、任务筛选、日志及错误状态，不以编译通过代替视觉检查。
- 核对简洁/高级切换前后的草稿和有效筛选不丢失，默认登录页只有一个秘密输入，手机导航可用键盘和 Esc 关闭且恢复焦点；浏览器禁用存储时仍可使用。
- 浏览器离线夹具与真实后端联调分开记录；没有执行的 MySQL、机器客户端、模型和公网检查不得写为通过。
- 正式代码、资源、页面标题、存储键、日志和文档只出现 TeaNeko 自身命名，交付前对本次新增内容检查。
