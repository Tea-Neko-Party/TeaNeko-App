# 第二批素材采集交付记录

日期：2026/11/03。当前进度与下一步统一见[实施入口](agent-expression-stickers.md)，配置、API 和生命周期统一见[素材模块](../../../src/main/java/org/zexnocs/teanekoagent/sticker/README.md)。本记录保留本次实现及离线验收事实，不作为另一份当前规格。

- 新增真实人类图片监听与注解收藏工具，普通聊天不等视觉任务；当前消息/直接引用经原消息端口验证，工具不接受任意 URL 或跨区域身份。
- 队列、限额、内容摘要、分析缓存和文件回收由 agent.sticker.v1 的专用 DTO 根事务仲裁。实例 catalog-id 与共享素材卷身份绑定，记忆 clear/reset 不触及图库。
- 下载、真实解码与暂存发布有界；原动画保留，GIF 合成采样在同次视觉输入中分析。帧尺寸在解码前验证，当前不可靠的动画格式明确拒绝。
- 默认视觉端口使用 SYSTEM/STICKER_ANALYSIS、一次模型、零工具；宿主独立检查类型、置信度、质量和类别，插画不强制收藏。同图缓存避免重复分析，不确定计费结果不盲目重试。
- 入库后才保护新项；旧项替换遵守固定、发送占用、类别、数量及可配置权重。目录与文件并非跨资源原子事务，先登记预约和元数据，发布后激活；清理成功后释放容量。
- 本地采集关闭继续收敛待处理作业与暂存，已有图库保留；重启旧租约超时后记录不确定状态。来源/插件/配置变化阻止迟到激活，已形成终态的任务不能再次激活。
- 分析器、目录、文件及准入策略采用独立接口、注解、Spring Bean 和 scanner 注册，不手动实例化已管理实现。

离线验证：

- 集中回归 111 个测试类、1023 项用例，1022 项通过、1 项原真实模型用例跳过。新增五项测试复用原 EasyData 事务夹具，覆盖共享去重、插画缓存、晚到拒绝、容量与固定/占用、写失败回滚、真实替换、文件动画、地址限制与懒装配/严格视觉协议。
- 最后补充关闭清理、有类型状态、激活保护期及动画解码前尺寸约束后，定向五项通过；随后强制重建生产/测试类及两个 JAR。完整回归与最后定向结论分别保存，不把两次测试数相加。
- 两个 4.6.1-l JAR 各含 1457 个生产类，逐字节匹配当前编译目录；23 项 Spring metadata、可执行包原生访问声明及 stickers.yml/expression.yml 模板同时核对。
- 83 个工作区相关 Java 文件、746 项显式声明通过中文 JavaDoc 与标签审计，完整 JavaDoc 生成；文档相对链接、外部名称隔离及 git diff --check 通过。
- 日志与统计保存在 build/tmp/stickers：regression.log 是集中回归，final-build.log 是最后定向及强制重建，javadoc.log 保存文档生成；验证摘要记录类、模板、链接和实际测试结果。

未运行真实模型、OneBot、MySQL 或全应用启动，未发送真实群消息。实际分类质量、动画体验、多副本共享文件与长期磁盘/网络负载留在部署清单。类别选择、独立发图、原生表情和管理 UI/SPI 尚属后续批次；未改版本文件、提交 Git 或发布标签，既有用户改动保留。
