# v4.8.3-l 统一结构化输出

## 范围

修复原生图片输入的模糊错误，以及后台 JSON 任务只声明提示、未启用输出选项的问题。复用类型描述工具，提供按 Java 类型生成结构说明并异步返回该类型的 LLM 入口。

- [x] 统一 JSON 选项、Schema 描述、适配器能力与不支持时的告警；类型描述只在初始化或显式重扫构建。
- [x] 统一严格解码与安全诊断；可选受限本机原始输出，保留权限、预算、取消及数据提交边界。
- [x] 迁移表情包、记忆、人格、主动发言及旧回复信封，修正入站容量诊断。
- [x] 定向回归、文档、JavaDoc、构建及产物核对。

不修改真实数据库或本地配置，不调用真实模型，不发布。JSON 模式不等于 Schema 强约束；适配器按实际支持映射，不为解析失败增加隐含重试。工具参数和持久 JSON 属于不同边界，不替换成模型生成调用。

## 当前状态

2026/11/06：约定实现与离线验收完成，100%。版本保持 4.8.3-l；未提交、打标签或发布，未操作真实数据库、模型和客户端。

根因包括素材分类与中期压缩未启用 JSON 选项、独立长期整理要求数组，以及仅覆盖模型身份时默认 TEXT 清除 JSON 意图。现已修正，并将六类输出接入共用类型描述和严格解码。主动发言保留原 Agent 管道；旧回复信封复用解码器，普通聊天不强制 JSON。工具参数、宿主工具结果、配置和数据库 JSON 不属于本次生成入口。

入站图片原来将多个限制合并为通用异常，现分别说明张数、单引用、总量和格式；旧日志不能反推出当时具体触发哪项。JSON 失败提供安全结构、字段或行列；原文仅在显式开启受限本机诊断后保存。
