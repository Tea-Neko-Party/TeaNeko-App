# 引用图片工具回填修复

版本：4.6.0-l。实现及约定离线验证完成，完成度 100%。根因：工具只返回字符串，图片 URL 被编码在 JSON 文本中，没有进入下一次模型请求的真实图像内容块。

## 实现规格

- 保留字符串工具执行接口与插件环绕；绑定可显式投影为文本和已校验图像，不从任意文本中猜测图片 URL。
- 工具批次先完整回填全部 TOOL 消息，再追加带调用关联的视觉参考 USER 消息，沿用既有模型图像协议、能力检查与预算。
- OneBot 消息查询只将同 scope 校验通过的消息图片接入此通道，支持 HTTP(S)/data 图片；图像负载与工具文本预算分离并有独立上限。
- 历史投影只允许与实际工具结果严格对应的视觉参考消息，移除这些临时图像，不伪装为用户原文或长期记忆。
- 必要测试覆盖真实 OneBot 工具到下一次模型序列化、完整工具配对与历史投影，以及非法或超限图像。

## 完成记录

- 已实现显式 LLMToolOutput 投影、包装保留、整批工具后视觉回填、OneBot 图像协议和严格历史身份验证。
- 新增三个必要用例：HTTP/长 data 图片的完整 OneBot 工具往返及 DeepSeek 请求序列化两项，非法/超量图像与普通 URL 不自动转图一项；同时验证多工具配对及伪造 USER 拒绝。
