## 用户原文

> 当前一次LLM调用的info信息，有点过于臃肿，分析并解决。将 INFO 改为单行结构化摘要，DEBUG 仅记录受限长度的内容预览，完整请求与响应交给独立的诊断日志；同时优化 LLM 输入结构和记忆去重机制。日志打印的只是应用选择展示的输入对象，不一定包含完整的 System Prompt、工具定义或服务端实际计算的 Token 上下文。同样也这里本允许的个性化报告，但是要还是在这基础上进行简化。此外可以从这个日志中发现很多问题，例如记忆提取发生了明确的重复。
