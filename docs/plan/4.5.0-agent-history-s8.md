## 11.77 第 38 批完成：持久化任务服务（2026-11-01）

交付 AgentScheduledTask、EasyDataScheduleStore、AgentScheduleService 和 TaskPresentation。服务包含创建、分页、详情、取消、明确时区、单次及固定秒数重复、Core Timer 适配和启动恢复，使用 Agent 专用 EasyData 的 agent.schedule.v1 域，无 Repository 依赖、独立数据库或线程池。创建先提交再返回，同一请求重放不重复创建，也不复活终态；不同规格占用同一 ID 拒绝。

按任务 ID、原计划时刻及修订号在数据库内比较交换，只有实际交换成功者执行，不能把其他调用方的认领快照误当成功。执行器在每个真实副作用前等待当前权限和权威任务检查；取消失效旧回调，迟到结果不覆盖取消。检查与外部副作用间的原子防重由动作后端负责，已经开始的外部动作不声称撤销。不明结果停止，不自动重试；权限未知或禁用暂停，数据保留。启动恢复将旧 RUNNING 标为不明，过期单次失效，重复任务跳到未来；不补跑错过的写操作。

只新增三项关键测试，复用原真实 EasyData 事务夹具，覆盖提交、防重及冲突、来源隔离、并发认领、取消竞争、策略拒绝、重启与固定间隔恢复。最终强制编译及回归为 98 类 950 项，949 成功、真实模型 1 项跳过。累计 95 个 Java 文件、157 个类型和 809 个显式方法通过中文 JavaDoc 审计；原生 JavaDoc 零错误/警告。实际 JAR 的 137 个受影响生产及内部类字节与编译结果一致，原始答复、早期归档、内置 Skill 及退役存储检查保持通过。

用法及限制集中在 [任务说明](../../src/main/java/org/zexnocs/teanekoagent/schedule/README.md)，日志位于 build/tmp/s8-schedule 的 targeted.log、regression.log、review.log、javadoc.log 和 test-classes.txt。当前是宿主可组合的调度服务，没有默认后台动作；原生命令、真实提醒、自然语言候选和主动级别仍待实施。启动恢复要求单宿主拥有者，批量历史记录的扫描延迟及真实 MySQL/OneBot/完整启动尚需实机验收。整体约 **88%**，S8 未标记完成。

## 11.78 第 39 批完成：原生提醒命令、实际发送及启动接入（2026-11-02）

交付默认 AgentScheduleConfig、应用就绪恢复与关闭生命周期、NativeScheduleAdapter 当前身份/提醒动作，以及 remind/tasks/task/canceltask 原生命令。构造不访问数据库，命令等待启动恢复后执行；恢复失败关闭调度并保留任务记录。创建从真实原生消息固定 UUID/client/scope/来源，以同消息稳定 ID 防重，先持久化再反馈；全部命令完成阶段包含实际反馈等待。时间需提供明确偏移和时区，不一致、夏令时空洞或含糊输入拒绝。

群身份每次通过原平台成员接口查询，核对平台 ID、原 UUID 映射、当前角色和 Agent 登记/启用；私聊限定原 UUID 的原平台账号。读取/取消只允许本人或当前群管理员，禁用后仍可管理，列表逐项跳过其他用户无权读取的任务，按页内计划时间展示。后台任务不构造原生高权限来源，也不安装命令、代码或文件动作。

普通文本提醒沿用原发送器，发送前复核取消、当前权限与实际目标，关闭发送自动重试和失败持久化补发；等待真实回执，未知或失败停止，不自动重发。平台没有幂等提交接口，不能保证网络意义上的恰好一次，也不能保证撤销已开始的发送。

只新增两项必要闭环用例，复用真实 EasyData 事务夹具及现有平台接口，覆盖原生命令提交后反馈、重放、发送等待及不明结果、成员/管理员归属、禁用后管理、私聊目标和时区拒绝。最终回归为 99 类 952 项，951 成功、真实模型 1 项跳过；强制编译、实际 JAR、中文 JavaDoc 及原生检查通过。累计 100 个 Java 文件、164 个类型和 838 个显式方法通过文档审计，142 个受影响生产/内部类与实际 JAR 字节一致，原始答复及早期归档保持不变。

用法只维护在 [任务说明](../../src/main/java/org/zexnocs/teanekoagent/schedule/README.md)，命令模块保留链接。证据位于 build/tmp/s8-native-tasks。未发送真实消息，MySQL、OneBot、完整启动及扫描性能仍需实机验收。整体约 **91%**；下一批为自然语言任务候选和三级主动触发，S8 不提前标记完成，S9 平台及最终清理仍保留。

## 11.79 第 40 批完成：当前原文任务与三级触发策略（2026-11-02）
