管线在步骤前、提交时及完成时检查 revision；异步返回 SKIP 同样不能把过期快照交给下一步骤。一个 Entity 实例只允许一个在途管线，其他实体独立运行；同一业务 ID 对应唯一实例的保证留给上层注册表。本批没有静态全局 World，也未新增私有执行线程池。

组件值需要调用方使用不可变对象/防御性集合；Core 容器不对任意业务对象深拷贝。执行取消不会回滚已完成步骤或外部副作用，HTTP 等后续适配器需通过 termination 信号释放自己的资源。
