## 撤销候选与期间变化

- **V486-D03 不再作为缺陷**：审查早期怀疑共享指针清理后无恢复。最新 `EasyDataLayeredMemoryStore.maintain()` 已逐批调用 `indexShared`，并让分区内游标循环。继续保留“清理后能恢复且不复活旧代次/过期消息”的实机验收，不另写第二套补建器。恢复速度受开关、分区数和页预算影响。
- **临时测试编译失败已解决**：首轮遇到 `PrivateContactTransportTest` 的 Mockito 泛型捕获问题；并行实施已改为 `thenAnswer`。最终回到正式 test 源集、无排除，159 项回归及 4 项诊断成功。中途隔离日志只作历史，不登记当前编译缺陷。
- **浏览器替身问题已纠正**：最初日志 API 替身缺 `policy`，补齐后最终 `pageerror=[]`；不把夹具错误写成产品异常。
- **S01–S08 已完成归档**：当前社交/共享记忆实施记录报告 349 项定向回归等验收，是实施历史，不能冒充本轮独立重跑。新实现收尾后复核了指针补建及关键诊断源码快照。
- **收尾装配修改另行复核**：并行实施将社交/共享记忆的运行依赖延迟取得，并用组件资料归属标记避免混入全局宿主来源。本轮补跑 `SocialComponentWiringTest` 9 项通过；真实完整应用和数据库启动仍未验收，不扩大这组检查的范围。
