# v4.9.1-l 表情包独立视觉模型验收

2026/11/10 完成实现及隔离验收，未发布、部署或重启真实应用。后续真实模型、数据库与客户端检查见[环境验收入口](next-steps.md)。

## 已完成行为

表情包组件默认完整跟随聊天 LLM，也可选择已有模型或填写私有连接。模型字段复用通用参数、秘密保留和装配版本合同；插件自行声明配置及检测入口，宿主不按表情包标识添加字段分支。

“插件配置 → 表情包识图模型”管理全局备用，保存并应用 `config/agent/sticker-model.yml` 后供新作业使用。主模型路由、凭据或图片能力不可用时可直接使用备用；已经发起的主请求失败后，等待真实结束并再次复核资格、版本和采集额度，最多再调用一次备用。取消、资格撤销及配置变化不接管，相同实际模型路由不重复调用；无备用和有备用分别限制为一次和两次模型调用。

两处检测均只调用本处选定的已保存模型，不调用备用；发送打包的 96×64 红方块、蓝圆合成图和固定问题，无聊天内容、工具或图库素材。只有正确识别颜色、形状和左右顺序才判成功。检测限制一次请求、60 秒及实例两个并发，实际完成后释放临时凭据和并发槽；页面以修订号、插件代次和草稿状态拒绝迟到结果。

Responses 原有 `input_image`、`image_url`、`detail` 及内联图片映射已存在。本轮补充可选 `image-input`，允许兼容型号明确声明图片能力；省略仍按已知型号判断，`false` 禁止图片。声明仅用于本地准入，不作为额外 API 参数发送；检测成功不自动改写模型文件。

旧非空 `stickers.yml model-id` 在未配置新备用时保留为兼容备用，不再覆盖组件首选。关闭旧备用须同时清空旧字段。操作和完整边界以[图库说明](../../../src/main/java/org/zexnocs/teanekoplugin/agent/expression/sticker/README.md#独立识图模型与检测)为准。
