# v4.9.1-l 识图检测入口与按钮间距修复

2026/11/10 完成。此前[视觉模型验收](sticker-models.md)使用的浏览器 API 替身未覆盖新接口的真实安全路由，本轮补上真实 Spring Security 与控制器回归。

## 原因与修复

组件和全局识图检测控制器已存在，但两个 POST 路径未进入安全链的管理员路由，落入默认拒绝。`@WebManagedEndpoint` 只控制错误响应格式，不开放 HTTP 入口；重新登录或修改配置白名单无法修复这一遗漏。新增回归在修复前失败，检测请求未进入异步控制器。

App 提供 `IWebAdminRoutes` 静态扩展契约，插件通过独立 Spring Bean 精确声明两个 POST 路径。声明在安全链初始化时装配，不扫描请求、不在宿主加入插件业务路径，也不开放整个插件前缀。登录、防伪、HTTPS 来源、插件资格、文件授权与聊天配置版本继续生效。

全局设置页为模型表单后的操作栏增加 `1.25rem` 留白，仅影响此页的保存、刷新等按钮。已有模型和私有模型模式均适用，窄屏仍正常换行。
