# v4.9.0-l 后续环境验收

模块重构的实现与隔离验证已完成，结果见[验证记录](verification.md)。以下项目本次未运行，不能引用旧版本的环境结果作为本次通过证据；不需要继续补写相同功能来代替环境验证。

| 环境验收 | 操作与通过条件 |
| --- | --- |
| 真实 MySQL 升级 | 在备份副本上启动本版，检查旧平铺装配、`shared-memory`、命令工具开关及精确白名单迁移；重启不重复更改版本。冲突原行保留，既有事务、WRITE 行锁、联合记忆/人格写入及历史表保持原合同。 |
| 完整生产启动 | 使用实际配置、插件、数据库及前端运行 JAR，确认应用启动顺序、插件阻塞原因、重试和最终关闭排空。生产目录 smoke 使用隔离业务依赖，不能替代此项。 |
| 真实模型 | 停用全部可选 Agent 业务插件后完成基础模型会话；恢复认知、表达、社交、自动化后原选择和隐藏参数恢复。分别检查共享模型与聊天私有凭据路由。 |
| 真实客户端 | OneBot 查询/发送过程中停用插件，确认迟到查询不能新增平台操作、已提交发送保留真实回执；恢复后无重复定时任务或过期单次补发。验证插件客户端连接关闭及事件排空。 |
| 多会话管理 | 实际浏览器会话经前台轮询或重新聚焦同步启停；已打开专页、弹窗、秘密详情和配置区域撤除，直连服务端拒绝失效插件。 |
| 日志与模型输入 | 以生产配置确认诊断目录权限、滚动保留和控制台隔离；真实模型正确理解原话字典，保留作者、否定与时间变化。记录实际输入规模和供应商报告用量，不按应用预览估算服务端 token；核验检查点重启后不重复学习。 |
| 运行负荷 | 在实际聊天与业务数据规模下检查迁移耗时、插件停止耗时、连接排空及长时任务资源回收，记录环境和测量值。 |

登录后默认开放已注册管理资源。环境验收同时覆盖缺省开放和 `local-allowlist-enabled: true` 的显式收紧模式；收紧时仍只迁移原已授权键，空列表拒绝访问。按[管理指南](../../development/plugins/management.md)核对当前模式，保留原配置和数据备份。

既有环境项目仍可查阅[部署验收清单](../../development/agent-deployment.md#实机验收清单)及[前版未验项目](../4.8.7-l/next-steps.md)。本次未执行部署、发布标签或远端推送。
