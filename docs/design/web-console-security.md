# Web 控制台登录与公网安全设计

日期：2026/11/03。状态：待实施安全合同，不表示已完成认证或可以直接暴露当前应用。界面需求见[控制台体验](web-console-experience.md)，通用资源合同见[管理接口设计](web-management-api.md)。

## 令牌生命周期

建议新增敏感文件 config/web/security.yml，通过既有 FileConfig 和 Core YAML 环境占位符加载，例如 admin-token: "${TEANEKO_WEB_ADMIN_TOKEN:}"。显示配置来源和“已配置”状态，不回显令牌；此文件不进入通用网页源码编辑或配置导出，仅本地维护认证根配置。示例中的文件名和字段尚未实现。

- 配置存在且有效：使用该值作为本实例管理员登录凭据；最低长度与允许格式校验，短口令或明显占位值拒绝开启管理服务，不用形式上的长度宣称已经证明随机性。建议使用随机生成的至少 32 字节秘密。
- 确实没有配置或值为空：每次应用启动使用 SecureRandom 生成 32 字节秘密，编码为便于复制的 URL-safe 字符串。每次启动只生成一次，普通 reload 或访问登录页不重新生成，不写回用户配置。
- 配置无法读取、环境展开失败、解析或校验失败：管理网络入口保持拒绝，不把“坏配置”解释成“未配置”，不降级匿名或默认密码。
- 随机令牌供本机操作者从受限运行文件取得，例如 data/web/runtime-admin-token；文件权限限制当前服务账户/管理员，不能通过静态资源、文件下载、日志查询、Actuator 或配置 API 读取。创建或保护文件失败时不开放管理入口，不回退到普通日志打印明文。
- 本地显式更换令牌或从有配置改为无配置属于凭据轮换：发布新的认证代次，撤销旧会话与实时连接。自动生成令牌时的普通配置重载保持当前值；应用重启始终生成新值并使旧会话失效。

运行时验证值尽量只保留不可逆校验值，比较采用恒定时间方式；令牌和请求体不进入普通日志。管理员令牌可配置为支持多个独立主体的凭据集合，但首期单令牌就是共享本地管理员身份，不能据此声称能区分多个自然人的审计归属。

## 登录与会话

管理员在 HTTPS 登录页提交令牌；服务端校验后创建独立随机会话，并明确授予本地管理员这一服务器角色。ManagementAuthority 将该角色映射为已注册管理资源的相应权限；未显式授予的未来资源默认拒绝。该身份不是某个 OneBot 用户，也不自动成为所有命令的 DEBUG 身份。

浏览器保留会话 Cookie，不长期保存根令牌或把它作为每条请求的 URL 参数。建议使用 __Host- 前缀、HttpOnly、Secure、SameSite=Strict、Path=/ 且不设置 Domain；退出、超时、凭据轮换及重启都在服务端撤销会话。服务端检查空闲和绝对期限，不能依赖关闭浏览器实现过期；建议初始空闲 30 分钟、绝对 8 小时，具体值可配置。

登录成功轮换会话标识，避免沿用匿名会话。登录端点限制请求体、尝试频率、并发和全局预算；失败返回统一信息，使用有界延迟/冷却，不因单个攻击来源锁死全部操作者。代理 IP 只信任显式配置的代理，不接受任意 X-Forwarded-For。根令牌不进入 localStorage、sessionStorage、URL、SSE 查询参数、WebSocket 子协议或客户端错误采集。

同源 SPA 用 Cookie 访问 HTTP 和 SSE。写入、上传、指令、退出等状态改变操作采用 CSRF 防护及 Origin/Referer 检查；SameSite 不能代替 CSRF。会话失效时终止订阅，重新登录不自动重放上次写请求。将来支持程序化 API Token 时另建明确传输和权限合同，不复用浏览器中可读的长效根凭据。

会话方案依据 [OWASP 会话管理建议](https://cheatsheetseries.owasp.org/cheatsheets/Session_Management_Cheat_Sheet.html)；请求默认拒绝与显式权限映射可由 [Spring Security](https://docs.spring.io/spring-security/reference/servlet/authorization/authorize-http-requests.html) 实现。具体安全组件版本由项目 Spring Boot 依赖管理选择，实现时核验版本 API，不根据设计文档固定一个未验证的版本。

## 全入口的默认拒绝

统一安全边界优先复用 Spring Security，不能只在登录 Controller 或前端路由判断。静态登录页面和必要静态资源可以公开，其中不包含运行数据；登录接口仅接受受限认证请求。其余管理读取、写入、配置 schema、日志、附件、导出、消息、SSE 和 WebSocket 握手/帧均鉴权。未知路由和未来未声明的端点默认拒绝。

资源授权除登录状态还检查当前主体、目标、动作、插件启用代次和必要版本。targetRef、消息 ID、operationId、文件 ID 都只是定位，后端不因为猜到了 ID 就开放数据。实时连接按会话/范围过滤，限时重新核验和主动撤销，不能握手检查一次后无限期放行。长操作在实际副作用之前再次检查授权；已提交或已外发结果不能靠退出登录声称回滚。

认证错误不泄露异常链或配置值；页面访问保护不能代替 JSON API 保护。SPA 回退、静态文件处理、错误转发、下载控制器和新增端口必须纳入入口清单。默认不将 Actuator 敏感端点公开；若使用独立 management 端口，也须限制网络及鉴权，避免从另一端口绕开。

现有 WebSocketConfig 为已注册客户端挂载 /ws/{client} 并允许所有 Origin，该行为不能作为公网安全保证。新增管理登录前必须一并核验已有入口：OneBot 等机器协议采用独立受限凭据/握手校验和连接身份绑定，不使用管理员浏览器会话，也不能为兼容而 permitAll 放开 /ws/**。不支持机器认证的已有入口须置于受限内网/本机端口并由网络策略保护，不能和公网管理入口一起裸露。后续 Web client 使用自己的浏览器会话和明确 Origin 白名单。

OneBot 连接“已认证”与“已握手”“自身账号已确认”分开。客户端自报 selfId 不替代凭据检查；多个连接须绑定实际账号，断开使相应连接代次失效，不能依据旧缓存继续执行指令。浏览器命令、管理权限与机器凭据相互独立，不能从其中一种换取另一种。

当前平台入口使用原生 WebSocketHandler；不能照抄 STOMP 消息授权示例就宣称全部帧已经受保护。实现时按实际传输验证握手、Origin、会话/机器身份和每类消息的访问边界，断连和撤权须释放已登记连接。

## 文件、消息与审计

配置读写只操作已注册 FileConfig/受控目录，不接受绝对路径、相对跳转、符号链接逃逸或任意环境变量读取。认证根配置不能通过普通文件编辑器修改。模型凭据等敏感字段只写不读，局部修改保留未改变的原始占位符；服务端也要验证，不依赖表单隐藏密码框。

聊天消息、日志、记忆、模型返回和插件文案都作为非可信内容显示；Markdown/HTML 采用安全渲染与必要清洗，不执行脚本。媒体采用受控认证资源；上传限制类型、大小、像素、数量、保存位置和解码开销，防止把富聊天扩展为任意文件服务或网络抓取代理。首期不执行插件上传的任意前端脚本。

审计至少记录主体、认证代次、目标、动作、operationId、时间及真实结果，日志不得包含根令牌、Cookie、密钥和原始敏感配置。共享单令牌只能记录共享管理员和会话关联，不冒充自然人身份。可靠安全审计与可丢的实时通知分开；日志/审计导出本身要记录并限量，普通实时日志采用有界缓冲和脱敏。

公网建议 HTTPS 同源部署，经明确配置的反向代理或直接 TLS；容器端口不要额外公开成为绕过 TLS 的入口。CORS 默认关闭跨源授权，仅按确有需要的来源开放；配置可信 Host/Origin 和代理链，不能泛用 *。会话页面、敏感 API 使用禁止共享缓存及合适的内容安全策略，不能因缓存命中泄露另一会话数据。

首期单实例最简单；若部署多个 Web 副本，必须明确共享认证代次/会话/限流与消息资源策略，或限定控制面只由单实例提供。随机令牌是每个启动实例的凭据，不可默认把独立随机值的多个副本放在同一负载均衡后。扩展部署需另行定义协调，不能宣称当前默认已支持。

## 必要验收

只测试关键风险，复用框架及已有业务夹具：无会话直接请求所有受保护 HTTP/下载/事件入口、未知路由拒绝；无配置随机令牌与重启失效、错误配置拒绝开放；退出/轮换/过期后的请求与已连接实时流撤销；CSRF、跨源握手和代理头伪造；跨目标 ID 越权、模拟成员越权和管理到聊天权限映射；秘密导出/日志泄漏；断线、换号、多连接不明确时指令不外发；配置并发写、环境模板保留及真实应用终态。

认证根、权限及实际部署没有完成上述核验前，不把“有登录页”或“前端已隐藏菜单”称作安全完成。安全边界可通过实现和攻击性用例验证，但无法仅凭设计承诺绝对不存在任何漏洞。
