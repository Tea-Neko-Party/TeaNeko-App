# v4.8.6-l

状态：待发布。上一版本已按 Gradle 流程提交并创建本地标签，本版尚未提交或推送。

## 改动

- 请求日志默认显示统计摘要、本轮用户输入和最终回复，采用文字分组。支持 INFO、DEBUG、NONE；Schema、system、推理和工具链分别可选。历史助手对话不重复输出，密钥与令牌继续脱敏。
- 结构化输出增加长度、集合数量和字符串枚举约束，模型协议和 Java 校验共用。原生 Schema 模式不再同时附带全文结构提示，JSON 对象模式保留必要说明。
- 长期记忆默认聚合四个新增片段，最迟等待十分钟；明确重要事件可以提前触发。纯重复问候、无新证据的片段不调用模型，成功检查点包含提示和结构版本。
- 同字段、同场景的近义风格优先合并证据，避免换一种说法就新建记录。保留原采用水位、作者校验、逐字引用和事务回滚。
- 精简长期提取的输入，不再同时传送完整证据实体及重复映射。证据容量不足时保留未处理片段，避免漏掉原话却推进水位。
- 组件卡片显示依赖；记忆空间改用已存目录下拉。画像首屏和刷新自动越过空页，用户详情独立成页；共享事件与个人事实分区，原“记忆证据”改为维护区的“独立事实”。
- 新增跨聊天回忆、受控私聊、好感度、心情和主动关怀组件。跨聊天资料标明来源；受邀私聊复核真实用户及同空间，主动关怀沿用 ACTIVE、静默、冷却、次数上限和真实回执。
- 修复好感度、心情及跨聊天回忆在 Spring 启动时的循环依赖：组件目录只加载声明，运行服务在实际执行时取得；权限与记忆空间代次继续实时复核。
- 修复上述三个资料服务被重复识别为宿主全局来源而阻止 Agent 服务创建的问题。组件资料声明独立归属，只随显式装配执行；真正的宿主来源冲突报告具体类型。

## 升级

- 日志设置见[观测配置](../development/web-console-agent.md#info-观测)。旧文件中显式开启的诊断项继续有效，采用精简模式需改为文档默认值后应用。
- 批处理配置和有界检查点见[长期记忆](../../src/main/java/org/zexnocs/teanekoplugin/agent/cognition/memory/layered/README.md#从中期到长期)。新检查点不复制原文，随空间代次维护；不会自动重学已完成的旧片段。
- 类型约束使用[JSON 输出说明](../../src/main/java/org/zexnocs/teanekoagent/llm/framework/structured/README.md)中的 `@JsonConstraint`；自定义服务构造需提供原模型服务，用于请求前的协议准备。
- 社交能力需显式装配，原 Agent 不自动启用。参数、空间绑定、私聊条件及存储说明见[共享回忆与社交组件](../development/agent-social-memory.md)；旧消息索引由维护任务逐步补建，关系状态按空间代次隔离。
- 升级需重启后端；后台真实模型质量与数据库并发验收单独安排。
