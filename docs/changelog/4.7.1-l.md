# v4.7.1-l

状态：约定功能与离线验收已完成，尚未发布。详细范围见[实施记录](../plan/old/4.7.1-web-operations.md)。

## 控制台界面

- 登录页改为居中单卡片，保留令牌填入、可选记住和登录操作，帮助按需展开。
- 浅色背景统一为 `#F5F3ED`，使用茶绿强调色；提供跟随系统、浅色和深色主题。
- 桌面导航支持分组与折叠，手机使用抽屉导航，支持键盘关闭和焦点恢复。
- 新增默认简洁模式和高级模式。常用配置优先展示，字段说明、技术标识和详细筛选按需展开，切换保留草稿及待确认请求。
- 本地文件普通字段可直接编辑，未修改的秘密不提交；日志详细筛选收起后继续提示实际生效状态。

## 客户端与诊断

- “客户端”新增独立机器令牌管理，支持主动查看、复制、局部修改、空白放行、移除及持久回执查询；秘密不进入目录响应或浏览器操作记录。
- 机器令牌允许 0～256 字符，空白明确放行、缺省客户端拒绝；管理员认证规则保持独立。
- 机器令牌保存与应用分开，应用时核对其他认证根设置。策略变更撤销旧会话，但保留本次启动的随机管理员令牌，重新登录后可查询原结果。
- 启动安全配置错误区分阶段和原因编号；分层记忆失败日志新增阶段、模型状态、准入原因、批次及可关联的请求号，原提交与退避规则保留。

## 通用配置

- 聊天配置自动发现已启用管理器，分为 Agent 与其他功能；按真实客户端、账号和聊天筛选适用项，支持登记、修改、注销及原回执查询。
- 通用表单支持继承字段、泛型、序列化别名、枚举、空值及集合/对象 JSON；复用原字段校验、事务和版本仲裁，专用适配器保留受限绑定行为。
- 草稿及待确认请求按聊天和配置分别保留，切换时提示；保存继续检查原版本，草稿只保存在页面内存。
- 非敏感文件配置支持自动表单，未知热应用契约明确要求重启；新增 `core.runtime` 专用区，可保存并应用任务与日志观测设置。

## 定时任务

- 新增 `@TimerDisplay` 声明式分类、中文名称、用途、展示和控制意图，支持方法引用、类级声明及显式注册元数据；分类键冲突明确报告。
- 将原 Core Timer 与 Spring 实际注册任务纳入同一规则目录，保留各自调度机制；现有缓存、状态监测、签到、活跃度、客户端维护及 Agent 后台任务已分类。
- 网页支持分类、规则类型、状态、名称及分页，服务端先筛选再分页，改变条件重置游标。
- Spring 与关键维护任务显示只读，实际写入口同样拒绝暂停；可控 Core Timer 保留原版本门禁和回执，旧插件无声明时归入未分类。

## 机器状态与版本

- 概览新增系统/程序 CPU、物理内存、JVM 堆与非堆、处理器数、运行时长和真实采样时间。
- 首次 CPU 只建立基准，不支持的指标保留为空；区分堆上限、已提交量与实际物理占用，JDK 未提供的进程常驻内存明确标示。
- 机器指标通过独立的管理员接口读取，每秒最多实际采样一次；页面可见时按五秒间隔更新，离开、隐藏或退出时取消，防止重叠请求和旧响应覆盖。
- 新增自动版本资源生成任务，普通类路径与 JAR 均显示原版本管理器产生的实际构建版本；不新增手工版本来源。

## 使用与兼容

`app.version` 和 `-Dversion` 不再覆盖运行版本。使用 Gradle 构建会自动生成版本资源；IDE 直接编译时先执行 `generateVersionInfo` 并同步 Gradle 资源目录。

登录协议、管理权限、确认操作、配置版本检查及原回执查询沿用现有机制。模式只调整界面密度，不扩大权限。秘密字段继续明确选择修改动作；保存文件与应用运行配置分开。

普通配置分组 `settings-groups` 默认空，已有实例不会自动扩大可编辑范围；可明确允许 `general` 组或逐项登记管理器标识。自动文件表单同样须加入 `file-sections`。

界面偏好仅保存在当前浏览器，不保存聊天草稿、文件修改或接口请求；浏览器禁用存储时仍可使用本次界面切换。
