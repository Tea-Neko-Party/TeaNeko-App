## 功能变化

- 保持 Core → App → Agent → Client → Plugin；模型协议与供应商适配保留在 Agent，官方传输客户端保留在 `teanekoclient`。业务插件按 `agent`、`general`、`onebot`、`web` 分类。
- 认知、表达、社交和自动化独立拥有其组件、工具、配置、后台工作与管理接口。常规 OneBot 操作合并为公共插件，成员事件与请求审核分别分组。
- 插件总管理展示稳定 ID、功能、依赖、客户端要求与运行状态。启停先预览影响，保存启用意愿后等待真实资源转换；失败保留原操作回执并允许明确重试。
- `config/plugins.yml` 成为实例级开关来源，首次导入旧禁用列表。依赖插件停用时消费者联动失效，但消费者原启用意愿和业务数据保持不变。
- “插件配置”二级菜单根据本地模块贡献生成。停用后移除业务入口、目录项、已打开页面及轮询，服务端继续复核权限与插件代次。
- `memory` 合并原 `shared-memory`，通过 `crossChatRecallEnabled` 控制跨聊天回忆；人格仍可独立装配。旧命令工具开关迁为依赖 `tool` 的 `command` 组件。
- 修复多个插件扩展 `/agent` 时的 Spring Bean 命名冲突；`@CommandExtension(prefix = "/agent")` 将命令路由与组件名称分离。
- 补齐插件配置模板及插件管理、Core 在途调用的管理员 HTTP 路由，保持原会话、防伪和资源授权边界。
- 指令一览按方法实际聊天范围精确筛选；模型配置保持系统内置，不再随插件目录权限或业务插件启停隐藏。

- 插件使用 `@TeaNekoPlugin` 声明静态元数据；宿主身份单独注册，LLM 与 Tool 是系统原生组件。业务扩展只在 `teanekoplugin` 声明插件归属，Java 接口名称统一使用 `I` 前缀。
- LLM 模型能力独立位于 `teanekoagent/llm`，`component/llm` 负责 Agent 桥接。前端按 `app`、`features`、`shared`、`plugins` 分类。
- 宿主配置不再为插件集中提供业务字段和访问器；插件自行校验、迁移和读取参数。未知旧节点、显式关闭和受保护字段完整保留。
- 修复内部聊天成功结果被提前关闭的执行控制覆盖为“已停止”；表达计划通过插件自有键和类型化端口交付，人格解析不再写宿主保留键。

## 升级说明

- 重新编译 Java 接入方和前端。插件随应用装配，本版不提供独立 JAR 动态装卸，也不加载远程页面代码。
- 保留数据库表、namespace、客户端 ID、业务存储键和既有配置文件路径。启动迁移使用原事务与行锁；新旧字段冲突时保留原记录并报告目标摘要，不猜测覆盖。
- 插件停用保留原装配和隐藏参数，恢复后继续使用原选择。关闭可选 Agent 业务插件后仍允许基础模型聊天。
- 完成 token 登录后默认开放已注册管理资源、文件配置和指令台，旧配置缺少 `local-allowlist-enabled` 时也采用默认开放。需要收紧时设置该项为 `true`，原白名单按精确键生效，空列表表示拒绝。会话、CSRF、插件资格和真实平台权限继续校验，具体规则见[插件管理指南](../development/plugins/management.md)。
- 内置业务插件支持热启停；仅声明重启切换的第三方插件按实际运行状态展示待重启，不把保存意愿当成已经停用。
- 停用会取消真心话倒计时，恢复后保留原轮次参与数据，可手动结算；不会补发停用期间过期的自动通知。自动结束时间限制为零至一天。
