# v4.8.4-l：控制台编辑与独立空间管理

开发补丁，尚未提交或打版本标签。

## 新功能

- JSON/长文本共用弹窗编辑器，提供查找、撤销、JSON 格式化和语法定位；配置类及字段可用注解选择。
- Agent 工作区新增独立记忆空间、人格空间目录；画像可选择已存用户并查看已有平台映射与昵称。
- 指令台独立选择聊天；网页房间支持原事务内的管理消息发送。
- LLM 交互与 Agent 执行节点可输出 INFO，通过 `agent/observability.yml` 分别开关并热应用。

## 修复与调整

- 修复工具参数 schema 省略空字段时工具目录无法渲染。
- 组件卡片保持独立高度；按可扩展顺序排列，LLM 与工具优先；返回按钮置于左侧。
- `/cfg` 移除“业务字段”术语，保留有用的字段和扩展操作说明。
- 无效管理回执保留原操作编号；已确认写入后的刷新失败不会被当作写入失败。
- 组件及客户端管理目录缓存静态声明，重扫原子发布；插件撤权与连接检查仍实时执行。
- 异常诊断保留安全类型链、位置、HTTP 状态及数据库错误码；补齐配置、资料、异步维护等丢失根因的路径，移除消息原文日志。
- 独立人格编辑沿用版本、回执和备份；已提交请求在基础配置变化后仍可原样查询/重试，不重复写入。
- 控制台页面改用单一声明和按需加载；页面切换保留草稿及原操作，停止隐藏页轮询。退出前检查隐藏页的未保存内容，注销失败不清空。
- 修复增量构建遗留旧前端分包：启动资源及 JAR 只包含本次控制台产物，不影响其他应用资源。

## 升级

旧安全配置不自动覆盖。独立空间及观测入口需要在原白名单追加标识，详见[升级配置](../development/web-console.md#484-l-升级配置)；[工作区说明](../development/web-console-agent.md#独立空间)列出当前页面所需的完整资源集合。修改安全配置后重载或重启，并重新登录。显式空的指令前缀仍保持禁用。

编辑器确认仅更新草稿，不跳过保存/应用。独立空间查询不注册 Agent、不创建用户、不改变聊天绑定；原数据库键与组件装配兼容。
