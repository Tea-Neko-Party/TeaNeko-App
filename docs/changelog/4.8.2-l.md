# v4.8.2-l

状态：待发布。

## 模型配置

- 新增模型、完成编辑和确认删除直接保存磁盘，无需再次点击外部保存。保存与运行应用继续分开；未改密钥、环境模板和未知字段保留，保存前说明 YAML 会重排且不保留注释。
- 卡片提供真实模型检测：初始或编辑后显示“未检测”，完成后显示成功或失败原因。检测使用已保存版本，不读取旧运行缓存冒充结果；版本或权限变化后拒绝迟到结果。
- HTTP 401/403/404/429、连接、DNS、HTTPS 与超时提供固定说明，未知错误显示代码位置，不导出凭据或供应商响应正文。检测会产生一次真实调用费用，最长 60 秒、实例最多四个并发，使用配置中的完整输出额度。
- 服务地址与接口路径直接可见；修复私有模型协议下拉列表图标超高、文字拥挤的问题。
- 模型弹窗先显示协议、服务地址与接口路径，再显示路由和其他参数；API 密钥操作不再使用“秘密”字样。
- 缺少后端环境变量时直接说明变量名和启动环境要求，保留原文件；修复 HTTP 400 校验失败后仍锁住表单的问题。变量就绪后可继续保存，环境模板不被展开值覆盖。

## 网页聊天

- 聊天室顶部新增当前发言档案的权限下拉，确认后切换 MEMBER / ADMIN / OWNER，复用原成员事务、版本校验和操作编号，不清除输入草稿。私聊只更新原有唯一成员，不允许新增、替换或移除身份；网页角色不等同于网页登录管理权限。
- 当前发言档案的消息靠右，其他成员与 Agent 靠左。
- 房间目录新增垃圾桶按钮，经一次不可恢复确认删除该房间、消息及附件；保留用户档案、聊天配置和共享记忆，旧来源不能通过迟到发送恢复房间。
- 简洁模式隐藏详细操作回执，保留正常指令输出和必要错误提示。
- 修复正常发送时短暂闪出“原请求结果待确认”的问题；只有实际失败才展示恢复入口，仍保留原编号防止重复发送。

## Agent 失败说明

- LLM、表达编译及邮箱交付贯通安全诊断，后台与用户提示保留具体原因；上下文原始失败不再被后续执行停止覆盖。
- 默认通过原发送器回复失败原因，可在聊天设置关闭“失败原因回复”，或执行 `/cfg set agent failureReplyEnabled false`。取消、撤权、关闭仍禁止迟到提示；发送器失败不触发重复补发。
- 拟人协议优先允许普通正文，分段时提供完整逐行示例；头部、当轮标识和 END 错误分别说明。控制行边缘空白可接受，不完整信封及非法指令仍拒绝执行，不将控制文本直接当答案发送。

## 升级与验证

无需数据库迁移，已有聊天的失败原因回复默认开启。重新构建并重启后端、刷新网页后生效；本补丁未提交 Git 或创建发布标签。

验证记录见[补丁计划](../plan/old/4.8.2-web-model-chat.md)。真实供应商连通性需使用新增检测按钮确认，离线回归不会消费实际模型额度。
