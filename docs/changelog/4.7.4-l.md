# v4.7.4-l

状态：功能实现与离线验证已完成，尚未确认发布。

本补丁修复网页聊天输入受轮询干扰的问题，调整消息输入区，并简化聊天配置和会话导航。

## 网页聊天

- 消息增量轮询不再占用编辑锁，避免输入框反复禁用、失去焦点或闪烁；空响应不重建消息列表。
- 原发送回执的后台确认不清除新草稿，过期消息响应不能覆盖较新的读取结果；切换聊天或卸载时中止原轮询。
- 输入区左侧“+”添加图片，也可拖放单张图片。上传成功后显示预览，“×”取消本次附图；右侧箭头发送，继续支持 Ctrl+Enter，并避免组合输入误发送。
- “聊天设置”和“活动与记忆”直接定位当前平台、账号和会话，保留原配置草稿确认和业务授权。已选 Agent 会话直接展示工作区，可按需重新展开聊天目录。

## 聊天配置与显示

- 配置编辑区不再重复显示左侧已选聊天的名称和号码。
- 未登记时不展示默认字段，只提供登记入口；登记成功后显示实际字段。配置与字段说明直接显示，不再放入下拉说明。
- “其他功能配置”支持按名称筛选，已登记项以绿色圆点标记并优先排列；登记、注销及手动刷新后同步状态，切换聊天不保留上一聊天的标记。登记状态独立于功能字段的启用开关。
- 项目现有配置声明增加简短中文显示名；稳定配置键、数据库记录和客户端范围保持不变。插件可通过 `@ConfigManager.displayName` 提供短名称。
- OneBot 原始消息携带的群名称进入通用消息与聊天目录；用户昵称和显式联系人同步继续使用原平台提供的名称。
- 刷新图标统一为 22px 矢量图形，修正页头样式覆盖；加载时旋转原图标，保持尺寸稳定。
- 刷新按钮样式在组件内部维护，避免全局样式引用组件库生成的类名；发送图标使用既有主题对比色，修正未定义变量并适配深色、自定义配色。

## 状态与诊断

- 网页客户端的目录刷新返回本地持久账号，不再调用未实现的外部联系人发现。
- 已关闭的 Agent 资料功能返回明确的业务冲突和设置指引，不再作为未知服务器错误。
- 模型准入日志区分运行设置、有效参数、能力及凭据检查阶段，只记录安全异常类型和代码位置。记忆整理将配置未就绪与运行中资格撤销分别报告，失败继续保留原消息、片段和整理进度。

## 升级说明

旧模型配置必须为所选模型补齐真实 `context-window-tokens`，并保留 `max-tokens`。输入比例未设置时仍为 80%；不降低输出额度或使用隐含容量。修改文件后须重新加载配置或重启，具体模型容量按供应商声明填写。

本补丁不自动启用 Agent、人格或其他聊天功能，不迁移数据，不改变媒体容量、身份认证、配置事务或模型预算。实际部署版本切换仍未纳入实现范围。
