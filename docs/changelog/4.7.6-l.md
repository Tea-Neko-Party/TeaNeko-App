# v4.7.6-l

状态：功能与离线验证已完成，尚未确认发布。

## 指令目录

- `@Command.displayName` 提供独立中文名称，补齐正式指令与本地开发命令；原前缀、别名和权限不变。
- 卡片并列显示前缀与名称，交替底色区分；总体说明、默认入口和子指令分别以标题、说明卡片呈现，支持按中文名搜索。

## 迁移数据库与聊天目录

- 从所有适用且插件启用的配置管理器发现聊天，通过各自原 EasyData 入口读取，修复仅扫描 Agent 导致普通配置漏项。
- 已有账号也继续发现配置，旧 Agent 单游标重新建立通用目录；各管理器独立分页，继续发现不会反复从首页开始。
- 无法确认机器人归属的记录进入“历史配置（账号未归属）”；私聊仍须有原 TeaUser 平台映射。配置较多时可继续发现，完成后显式刷新可重新扫描后续导入数据。
- 离线历史配置不要求 OneBot 在线，平台联系人查询及指令执行继续要求真实连接和来源授权。

## 模型和文件配置

- 新增和已有模型统一提供选择列表与“手动输入”开关，保留旧名称和自定义型号；选择已知型号同步真实上下文容量。
- DeepSeek、Kimi 选项依据官方资料人工维护，随补丁更新，不自动请求供应商。具体选项和账号范围见[模型教程](../development/web-console-models.md#维护的型号列表)。
- 文件类型及字段的 `@Description` 直接展示；专用表单复用原解析器按真实 JSON 指针解析说明，支持嵌套、数组、泛型和别名。补充总开关、表达策略、网页容量及模型参数的解释、范围与单位。
- 只返回公开声明，原文件注释、秘密及环境展开值不作为说明导出；文件授权、预检、原子保存、回执和独立应用保留原规则。

## 网页房间

- 修复 Agent 普通聊天及 `/agent chat` 因“本轮资源资料证明无效”而结束为 `CONFIGURATION_ERROR`：媒体资料签名使用稳定 Map 键序，插件版本令牌经 JSON 往返后不再因遍历顺序改变而误拒绝。原防篡改、请求绑定、过期及插件复核继续执行。
- 上下文校验失败转换为配置错误时，记录关联请求、安全异常类型和代码位置，不输出异常正文、Prompt 或凭据。

- “聊天设置”“活动与记忆”成为并列房间子页，保持在网页聊天栏内并固定当前目标。会话设置按钮进入相同子页，与下方文字增加间距。
- 各房间保留独立配置草稿及待确认操作；返回目录或切换房间不混用，活动子页隐藏后停止轮询。
