# v4.8.3-l

发布日期：2026/11/06。使用项目 Gradle 流程创建本地提交与注解标签，未推送远程。

## 表情包采集

- 补齐默认可信媒体域名 `multimedia.nt.qq.com.cn` 和 `gxh.vip.qq.com`，修复对应平台图片被下载白名单拒绝的问题。
- 修复采集宿主使用空预算，导致视觉交互在预检阶段返回 `INVALID_INPUT`、始终没有发出模型请求的问题；宿主与交互统一声明一次模型请求、零工具轮次和零工具执行次数。
- 下载失败明确区分主机或私有地址拒绝、DNS、连接、HTTPS、超时、HTTP 状态与文件大小限制；保留取消原因，不记录图片签名参数和响应正文。
- 视觉分析失败保留实际请求号、模型终止状态及已有的脱敏诊断，HTTP 状态、原错误类型和代码位置不再被覆盖成“未识别异常”。
- 模型输出截断、超时、拒答、空输出与配置错误分别说明；成功交互但分类 JSON 无效、缺少最终消息或超过字段容量仍拒绝入库，不将失败当成普通图片分类。
- 配置与输入预检失败保留真实代码位置，预算或消息契约错误不再统一提示为图片能力问题。
- 图片解码按真实动画子帧累计像素计量，区分格式、画布、帧数和损坏原因；恢复前帧时仅备份子帧覆盖区域，避免反复复制大画布。

## 模型与回复

- 增加统一类型化 JSON 入口：根类型标记 `@LLMJsonType`、字段使用 `@Description`，自动生成结构说明并异步返回对象。适配原生 JSON/Schema，不支持原生约束时明确警告。
- 表情包、中长期记忆、人格学习和主动发言接入共用合同；旧回复信封复用严格解码，普通聊天仍可直接输出文本。
- 修复模型身份、路由覆盖时默认 `TEXT` 清除 JSON 选项的问题；结构提示和 Schema 计入输入预算。
- 格式失败显示请求号、字段或行列、容量与脱敏输出结构；可临时开启受限本机原文归档，默认关闭。配置见[结构化输出说明](../../src/main/java/org/zexnocs/teanekoagent/llm/framework/structured/README.md#诊断)。
- 原生图片入站分别报告张数、单引用、图文总量和非法引用，保留原限制，不回显图片地址或签名参数。
- 修复工具续轮在预算耗尽后丢失工具定义，保留定义并以 `tool_choice=none` 禁止执行；供应商推理字段按协议回传，不作为用户正文。
- 修复双竖线、带空白及行内混排的 DSML 标记漏检；表达和 JSON 解码后再校验完整正文，不将控制标记作为聊天发送或工具执行，保留代码围栏中的示例。
- 工具尚未执行且原预算充足时，至多让模型重新提交一次规范工具调用；错误正文和临时提示不进入正常历史，不增加预算、不重复外部动作。仍失败则提供明确诊断。
- 表情包目录校验失败不再静默变成“无工具”；最终工具筛选与类别资料一致性在模型请求前检查，区分空图库、过期资料和查询工具不可用。
- 自动回复交付复核失败显示具体状态、目标或表达计划原因；资料复核异常保留原安全诊断，不再丢失来源失败原因。
- 用量告警显示请求号、报告量、估算量、阈值和未知调用数，仍只作提醒，不改变模型预算。

## 记忆整理

- 目录扫描与领取后的模型整理分别计时，扫描不再挤占生成时限。
- 修复同一次模型超时又被外层误报为目录失败的问题；退避或已发起的提交按真实持久化结果结束后，才释放在途占用。
- 保留原消息、租约与整理进度；迟到模型结果不能推进水位。取消、关闭和达到截止时间分别说明。
- 长期记忆统一使用 `memories/styles` 对象协议，无人格目标时 `styles` 为空数组；格式错误不推进水位，普通日志不导出模型原文。
- 修复事实学习关闭时，合法空人格观察批次被误判撤权、阻塞后续样本的问题；实际撤权仍拒绝提交。
- 长期证据校验区分原话、作者、片段及来源失效，附脱敏定位；生成预检与事务复核共用规则，排队耗时计入有效期，混合批次失败整体回滚。
- 相同输入三次无效生成后持久暂停；工作区可查看原因并按版本恢复。旧作业缺省字段兼容读取，恢复不跳过原进度或增加模型预算。
- 补齐领取租约前的目录/分区读取失败退避，避免每隔数秒重复读库及告警；坏分区不阻塞其他分区，成功读取后恢复普通轮询。这层退避仅保留在当前进程，不覆盖原持久记录。
- 持久格式错误显示 `MEMORY_STORAGE_FORMAT`、记录类型及受控字段，不泄露原话或 JSON；不再误计为模型无效生成，也不承诺三次后暂停。

## Agent 组件与扩展

- 修复后台长期整理在排队期间取消或撤权后仍可提交的问题；纯事实、风格和空候选均在事务内复核，不推进失效批次的水位。
- 人格可在没有记忆组件、关闭历史采集或自动摘要时独立学习真实用户表达；与联合观察互斥，保留原学习开关和冷却。
- 原生表情由 expression 独立提供当轮目录和发送许可，无需 tool 或 sticker，不再读写图库。
- 插件持久任务支持各自动作的创建/执行策略，继续执行公共身份及归属检查；停用插件后仍可读取、取消原任务。
- Skill 在工具白名单、插件和客户端筛选后重新检查完整依赖，缺失时拒绝该轮，不自动扩大工具权限。
- 修复单字长期记忆查询被误作空查询；模型及兼容工具目录在完整校验后原子发布，重扫失败保留旧目录。
- 主动候选公平轮转，模型槽位忙时不消耗完整周期；未安装 memory 也保留独立持久防重。
- 持久任务使用到期活动索引和四个有界执行槽，慢动作不阻塞后续发现；提醒须收到有效平台消息 ID 才算完成。
- 已回收文件的人工删除墓碑不占分析缓存容量，删除决定继续保留；空插件事件列表不再要求插件目录。
- 工具类声明、代理方法及参数绑定规则在初始化时预编译，每轮查询和调用只读缓存，实时权限复核保持不变。
- 修复共享同一 JDK 代理类的工具提供者串用声明；独立宿主按 Bean 身份隔离预编译规格。
- 修复不同 JDK 代理接口共用继承条件或业务方法时，后初始化者找不到调用候选的问题；候选随各提供者规格原子发布，仍经过真实代理与动态条件检查。
- 已回收素材的永久删除决定分行保存，解除其对主目录容量的持续挤占；迁移、恢复、版本和计数保持原子提交，管理接口提供真实容量与有界分页。

## 升级要求

无须手工改表，但首次图库访问会自动迁移已回收的删除记录。升级前备份数据库和素材卷，停止旧实例后统一升级；旧版本不能读取独立拒绝索引，不可混跑或直接降级，回退须使用配套版本的数据备份。迁移与管理合同见[图库说明](../../src/main/java/org/zexnocs/teanekoplugin/agent/expression/sticker/README.md#删除记录迁移与回退)。

重新构建并重启后端生效。已有 `config/agent/stickers.yml` 不会被模板覆盖；若 `allowed-hosts` 缺少 `multimedia.nt.qq.com.cn` 或 `gxh.vip.qq.com`，须手动补入并重新加载配置。

已有活动任务的到期索引在单宿主启动恢复时自动补齐。使用三参 `AgentTaskAction` 的插件需提供第四个动作策略参数，旧构造默认拒绝创建/执行。直接调用 `TeaNekoAgentToolMethods.select` 的独立宿主须在初始化时先调用 `prepare(bean)`；默认生产注册表已处理。

本补丁保留现有超时和模型输出额度。真实外部服务超过配置时限仍会失败，日志提供具体检查方向；离线回归不代表真实视觉供应商已完成联调。

JSON 调整不改变已有记忆和人格持久数据。自定义生成器若复用默认提示或模型输出夹具，须改为新的长期对象及 `adjustment` 人格信封；自定义模型适配器应声明 JSON 支持能力。使用共用服务的独立宿主需初始化 `LLMJsonSchemas`，生产装配由原重载服务完成。

旧图片可能已进入分析失败缓存，修复后验证可使用此前未采集的图片。需要重新判断既有缓存时，在素材配置中递增 `analysis-version`，仍受原采集额度约束。
