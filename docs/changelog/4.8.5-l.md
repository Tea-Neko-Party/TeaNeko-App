# v4.8.5-l

本地版本日期：2026/11/06。通过 Gradle 版本任务提交并创建 `v4.8.5-l` 标签；远程推送另行执行。

## 功能

- 组件与系统、工具目录改为对齐的摘要卡片；点击查看完整说明、参数及执行系统。长描述不撑大目录卡片。
- 工具目录支持客户端下拉筛选，并保留适用的通用工具；可与文字搜索组合使用。
- 每条 Agent 请求结束后输出一次 INFO 汇总，内部 LLM 不重复输出；独立 LLM 交互单独汇总。包含实际模型输入、工具声明与回执、响应、供应商返回的推理、耗时及 token 用量。
- 观测配置可选择上下文、推理和正文上限。凭据与媒体链接脱敏，截断明确标注；网页阶段时间线保持可用。
- 发送回执正文、维护游标、计划管理回执、已完成清理的表情包作业转入 `cleanable_data`。长期状态、必要防重摘要、在途作业和资源清理责任仍持久保存。

## 修复

- 修正嵌套 JSON 密钥、内联多项 Cookie 等观测内容漏脱敏。敏感值按结构隐藏；编码、畸形及超限输入保守处理，先脱敏再截断。
- 修正提前拒绝、配置错误和关闭后的请求缺少汇总。它们与正常完成共用终态通知，重复启动、取消及迟到结果不会重复汇总。

## 升级

- [观测配置](../development/web-console-agent.md#info-观测)新增内容开关，默认开启；日志可能包含聊天隐私，可关闭正文和推理，仅保留统计。
- 旧记录在对应事务或有界维护页中迁移，失败整体回滚。升级前停止旧进程、备份数据库，不混跑新旧版本；迁移后回退旧程序需要恢复迁移前的一致备份。
- 关闭自动 DDL 的部署需补齐临时表维护索引。数据分类、回收与迁移规则见 [Agent EasyData](../../src/main/java/org/zexnocs/teanekoagent/database/easydata/README.md)。
- 观察扩展接口改为终态 `finished` 回调；已有自定义观察器需要同步签名。模型结果的原构造入口保留。
