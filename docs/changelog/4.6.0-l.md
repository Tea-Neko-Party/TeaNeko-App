# TeaNeko App v4.6.0-l

## 版本重点

在新版 Agent 之上建立统一插件扩展机制。插件可以声明模块依赖，为指定 Agent 安装工具、资料、组件与 System，并通过可修改事件和类型化异步链参与业务处理；内置能力与插件采用相同组合路径。

## 新增功能

### Core 插件基础设施

- 新增 `PluginModule`、`PluginDescriptor` 和统一目录，校验插件 ID、SPI 版本、必需依赖、重复声明与依赖环；当前宿主 SPI 为版本 1。
- 支持启动禁用列表 `tea-neko.plugins.disabled`、运行期逻辑启停和状态查询；必需宿主模块不能通过插件开关关闭。
- 通过插件及传递依赖的版本令牌复核调用，拒绝禁用或换代后的迟到结果；无关插件的开关变化不统一作废其他调用。
- 新增 `@PluginOwned`，将命令、事件监听器、同步任务阶段及模型适配器接入统一归属和启停检查。
- 提供 `OperationPipeline` 类型化异步环绕，支持明确的前置、后置与结果变换，并约束下一节点调用次数、短路资格及真实完成等待。

### Agent 能力装配

- 新增 `AgentFeature` 能力包，按实例声明组合工具、资料、组件初始化、System 及资料解析拦截器；能力依赖自动展开。
- `AgentDefinition` 支持显式能力集合；插件化工厂在实例登记前检查声明和 System 依赖，拒绝半初始化实例。
- 区分实例不可变配置与轮次独立状态，组件使用所属能力的命名空间；插件 System 仅能写入声明的自有组件。
- 开放 `BEFORE_PROMPT` 和 `AFTER_INTERACTION` 两个受控阶段，复用 Core 管线的依赖、写入和版本检查；阶段前后继续复核宿主准入。
- 聚合内置与插件的工具和资料，重名明确失败；每个资料源只验证自己拥有的片段，实际输入保留能力版本供执行与完成重放检查。
- 插件校验步骤返回 STOP 时按 `SKIPPED` 拒绝交付，防止先前观察到的模型成功绕过最终提交检查。

### 事件、工具环绕与任务动作

- 新增 `AgentPromptPreparingEvent`：在输入预算裁剪前筛选、重排或补充已声明的低信任资料。
- 新增 `AgentToolsSelectingEvent`：在工具集固定前移除或重排原候选；新增工具仍通过能力贡献注册。
- 决策事件提供固定可信上下文和可冻结草稿，按实例安装范围过滤插件监听器；禁止独立异步监听修改决策，拒绝决定不能被后续监听撤销。
- 继续开放轮次报告和 Token 告警用于异步观测，监听失败不改变原业务终态。
- 提供资料解析的异步拦截和工具绑定环绕；保留原参数校验、预算、授权及取消边界，实际工具失败不能被包装成成功。
- 通过 `AgentTaskAction` 贡献持久任务动作，保留内置 `remind`，复用原 Timer、存储、防重、权限检查和真实副作用回执。

### 管理扩展与示例

- 新增传输无关的 `ManagementResource`、`ManagementGateway` 和可信管理上下文，支持类型化请求、字段描述及显式权限声明。
- 管理访问默认拒绝；只有安装宿主授权适配器后才能发现或执行资源，并在实际操作与返回时复核权限、控制和插件版本。
- 提供插件目录与 Agent 实例两个只读管理资源，为未来 Web 及命令适配保留统一入口；实例查询使用有界分页，不反射导出整个组件或执行资源。
- 提供默认关闭的时钟示例插件，完整演示模块声明、实例时区组件、轮次时间组件、前置 System、工具、资料环绕和事件监听。
- 按 Core、Agent、管理扩展拆分开发指南，说明公开 API、事件字段、可修改范围、数据寿命和实际完成语义。

## 行为调整与修复

- 修正 DeepSeek 思考强度的请求映射：`reasoning_effort` 使用顶层字段，只配置强度时不再生成缺少 `type` 的 `thinking` 对象；现有 metadata 配置名保持兼容。
- Agent 与 LLM 失败日志增加请求关联、执行阶段、异常类型及可取得的 HTTP 状态码，避免只剩固定失败文案；不输出密钥、对话、响应正文或原异常消息。
- 为 `bootRun` 与可执行 JAR 声明 JDK 原生访问权限，支持 Netty 加载本地库；IntelliJ 直接运行主类的 VM 参数见部署说明。
- `IAgentToolSource`、`IAgentPromptSource` Bean 在完整宿主装配中作为额外来源组合；新增总来源不再使内置记忆、历史和命令能力退让。
- 同优先级事件监听按 Bean 名和方法签名稳定排序，同优先级同步任务阶段按 Bean 名排序，避免扫描顺序影响业务修改结果。
- 保留 `TaskStageChain` 单线程推进调用栈的语义，允许链内启动异步任务；完整业务环绕通过返回的完成阶段组合。
- 资料过滤和包装保留插件版本信息，防止 Skill 或扩展资料剥离时丢失执行及重放守卫。
- 内部 Agent 客户端的惰性依赖改为明确限定的接口注入，避免为 final 实现类型生成 CGLIB 代理。
- 插件调用及管理上下文隐藏普通序列化和诊断中的执行资源，避免将完整请求或控制对象当作可展示数据。

## 兼容性与接入说明

| 接入场景 | 要求 |
| --- | --- |
| 新插件装配 | 提供 `PluginModule` 和明确 Spring 配置；外部 JAR 通过依赖及显式导入接入，按需登记类扫描根。 |
| 追加 Agent 能力 | 优先提供 `AgentFeature`，由实例显式选择；第三方能力默认不安装到所有实例。 |
| 旧总来源策略 | 不再依赖新增同接口 Bean 替换内置能力；保留一个明确宿主总来源，普通插件使用能力贡献。 |
| 组件及资料命名 | 声明自有组件键和资料来源名；跨能力重名或未声明写入明确拒绝。 |
| 异步拦截 | 返回包含前置、下一节点与后置的完整 Stage，不保存同步任务链游标作异步推进，不自行重试写副作用。 |
| 运行期开关 | `setEnabled` 为进程内逻辑状态，不自动写回文件；重启后重新应用启动禁用配置。 |
| 管理资源 | 可信身份由宿主适配器建立；写用例仍需领域服务实现版本仲裁、幂等与审计，管理路由不自动补出这些保证。 |

## 验证与交付边界

- 本版最新离线复核包含 100 个测试类、975 项用例，其中 974 项通过、1 项真实模型测试跳过；覆盖多能力组合、依赖换代、实际事件分发、工具闭环、管理授权、异步完成边界及 DeepSeek 请求序列化和失败日志脱敏。插件化阶段的原始验收数保留在已完成计划中。
- 强制构建普通与可执行 JAR，最新复核中两类产物的 1297 个生产类均与编译目录逐字节一致；可执行包原生访问声明、相关中文 JavaDoc、配置 metadata 和文档链接检查通过。
- 插件为随应用装配的受信任 Java 模块。逻辑禁用不等于销毁 Bean、卸载类或撤销已发生的副作用；资源仍由原生命周期拥有者管理。
- 本版不包含动态 JAR 上传和热卸载、独立 Maven SDK 发布或不可信代码沙箱。
- 管理 SPI 已提供基础查询资源；完整 Web 页面，以及记忆、群配置、任务运行、日志和实时订阅的网络适配仍需后续实现。
- 真实 MySQL、OneBot、外部模型及完整应用启动继续按部署清单验收；以上为交付时记录的离线结果，不代表真实运行环境已通过。
