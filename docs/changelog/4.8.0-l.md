# v4.8.0-l

状态：待发布。

## 可组合 Agent

- 新增注解组件目录、独立参数、版本化 JSON 装配与系统生命周期。模型、记忆、人格、工具、技能、表达、表情包、定时任务和主动活动可按聊天组合。
- 新登记默认只有 LLM，不保留上下文或采集记忆。已有未声明装配的记录保留原行为，不自动迁移。
- 人格解析、输入/输出历史和表达编译使用独立 ECS 系统；C/S 按职责集中到 `component`。卸载能力不会被默认工具或后台活动重新启用。

## 模型与管理

- LLM 支持系统路由与 Agent 专用 cfg 数据库中的私有模型，复用协议样板及环境变量解析，不写 `model.yml`。
- 私有配置不进入公共实体，密钥不回显；Web 显式保留或替换秘密，保留原事务、权限和版本保护。配置修改使旧路由失效。
- 聊天设置提供组件卡片、参数弹窗、依赖处理和脱敏 JSON 预览。
- 侧栏“API 文档”提供指令、组件/系统和注解工具说明，目录来自真实声明，只允许管理员访问。

## 升级

本版同时完成分层与目录整理：模型、记忆、人格等完整能力归入 `component`；运行生命周期归入 `runtime`。OneBot、Web 对 Agent 的适配回归 Client 层，内部客户端迁入 `teanekoclient/agent` 并保留原契约。多工具提供者拆为单工具类，共享业务服务继续复用。详见[项目分层](../development/project-layers.md)。

无需改写旧数据库记录。保存显式装配后，其参数替代对应的平铺字段；新登记需要完整能力时手动安装组件。卸载不删除已有数据。`/agent model` 继续工作，切回系统模型会移除当前私有配置。

引用已迁移公开组件类型的插件须更新 import 并重新编译。详见[装配说明](../development/agent-composition.md)与[组件开发](../development/plugins/agent-components.md)。

已完成隔离构建、自动化回归及装配界面的离线浏览器验收。本轮分层重构通过 1125 项隔离测试，并核对新包、旧类清除、前端资源和版本产物；正式部署及真实供应商验收保留在[部署说明](../development/web-console.md)。
