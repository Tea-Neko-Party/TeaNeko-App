# v4.7.5-l

状态：功能实现与离线验证已完成，尚未确认发布。

本补丁修复网页消息无法进入通用 Agent 监听链的问题，提供房间式聊天、权限化指令补全和独立模型配置。

## 网页聊天

- 通用事件监听器按实际事件继承关系合并。未被类扫描覆盖的网页子事件仍能触发原命令与 Agent 处理，同一监听器不重复调用。
- 网页私聊首次创建、进入或提交时，为缺失的配置原子登记并启用 Agent。已有显式关闭保留；群聊、本地总开关、插件和模型准入继续使用原规则。
- 网页回执等待原监听器登记的异步命令与 Agent 阶段，处理失败不再仅以事件通知成功结束。已保存消息及发生的外部动作不回滚，也不自动重发。
- 按私聊/群聊房间进入聊天室，可返回目录；聊天页保留消息和输入区，会话设置、成员与图片位于顶部独立标签页。同一房间返回后保留草稿。
- 引用直接显示作者与正文摘要，点击定位原消息；消息和引用 ID 仅在高级模式显示。手机端保持输入区可见，保留加号上传、拖放及附图取消。
- 输入 `/` 和子指令时提供补全，按真实房间成员、客户端、scope、权限与插件规则筛选。方向键选择，Tab/Enter 填入，Ctrl+Enter 发送，中文组合输入不误触。

## 配置与指令目录

- 新增“指令一览”，从实际注册命令展示完整说明、示例、别名、参数、权限与客户端条件。查看全局说明不改变成员身份，执行仍由原分发器复核。
- 本地配置文件与字段说明默认直接展示，模型从普通列表移入独立“模型配置”。
- 模型按路由分卡编辑，提供 DeepSeek、Kimi、OpenAI 公开样板，自动填写地址与接口路径；支持修改具体模型、输出额度和真实上下文容量。
- API key 可手动替换或填写环境变量名，环境方式写入原 `${变量名}` 模板。原凭据不回显，新凭据不进入浏览器存储，未修改秘密和模板保留。
- 自定义模型使用现有注册协议，自行填写服务地址和相对路径；已有路由也可修改连接。样板只进入当前草稿，保存到磁盘与应用运行配置保持独立，继续执行原文件授权、版本和回执规则。

## 扩展与升级

修复组件扫描启动失败：三个新扩展注解使用独立 `id` 保存业务标识，不再让 Spring 将 `environment` 等业务值当作 Bean 名，避免覆盖框架环境组件并消除隐式组件命名弃用警告。实现类及注册目录同步改用 `id`，网页/API 中已有路由与输入方式标识不变。

供应商目录使用 `@LLMConfigurationAdapter` 和 Spring Bean 贡献样板；`@LLMCredentialInput` 贡献页面输入编码。注册目录校验重复声明，并检查真实模型注册和插件启用。网页房间通过 `@WebRoomPreparation` 贡献幂等准备，不在客户端中硬编码 Agent 存储。

无需数据迁移。已手动关闭的网页私聊需要自行重新启用；默认启用不代表模型已配置就绪。模型页面仍要求安全文件开放 `agent.models`。更换实际模型时须同步核对真实上下文容量。新增样板不会触发供应商请求，保存和应用也不验证远端密钥、余额或服务可达性。
