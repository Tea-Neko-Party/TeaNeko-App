# v4.7.3-l

状态：功能实现与离线验证已完成，尚未确认发布。

本补丁完善网页控制台的布局、会话选择、刷新操作和配色设置，并让管理员直接管理适用的聊天配置。定时规则增加更完整的业务介绍，原调度与执行权限保持不变。

## 页面布局与聊天表单

- 运行概览和客户端页面的并排客户端卡片分别按自身内容确定高度，展开一张卡片的连接详情不再拉高旁边卡片。
- 网页聊天的创建按钮、会话标签和选择框分行留白；创建弹窗中的名称、类型与成员字段统一增加间距。
- “档案与成员”中的档案创建、群成员列表和成员编辑分块排列。成员档案、群名片、角色及保存操作分别留出间距，手机端自动纵向展开。

## 管理员直接编辑聊天配置

- 已登录管理员可直接查看、登记和修改适用于当前客户端且所属插件已启用的聊天配置，不再要求先在本地 `settings-groups` 或 `settings-sections` 放行。
- 页面移除本地分组授权提示；没有配置时显示当前客户端或插件暂无适用配置。
- 管理员会话、客户端命名空间、插件启用状态、字段校验、配置版本、事务提交及回执查询继续执行原规则。
- 旧 `settings-groups` 和 `settings-sections` 字段保留读取兼容，但不再参与聊天配置访问判断。文件配置和其他管理资源的白名单保持独立。

## Agent 工作区独立选择聊天

- Agent 工作区增加独立的平台、机器人账号和聊天目录，支持名称/号码筛选、目录更新及继续加载。
- 与聊天配置分别保留选择状态；点击“选择其他聊天”回到工作区自己的目录，不再跳转聊天配置页。
- 切换目标继续检查当前操作、补正草稿和待确认请求，旧目录响应不会覆盖新选择。

## 刷新操作与任务介绍

- 刷新、重新读取及更新目录的控件统一使用刷新图标，保留完整的悬停说明和无障碍名称；加载时显示单个加载图标，禁用和原确认流程继续生效。
- 日志分页、查询回执和业务写入操作保留各自的动作名称，不改变其请求语义。
- 为项目内 15 个定时来源补充执行对象、具体工作、可能的模型调用或真实发送，以及暂停或只读边界。涵盖 Core 调度/缓存/负载监测、Agent 计划/主动活动/记忆/素材，以及签到、点赞、群活跃度、头衔和入群申请维护。
- 介绍直接显示在定时规则卡片中；实际周期、时区、预计触发时间和运行状态仍来自原调度器，新增介绍不改变执行计划。

## 自定义网页配色

- 右上角新增“外观设置”，可通过拾色器或六位十六进制色值设置网页背景、前景文字和强调色。
- 在弹窗中预览配色，保存后立即应用；面板、边框、选中和按钮状态色随主色派生。
- 配色只保存在当前浏览器，刷新后保留；“恢复默认配色”重新采用所选的浅色、深色或跟随系统主题。
- 配色不写入服务端文件、不包含聊天正文或凭据；浏览器存储不可用时仍可应用本次界面偏好。

## 升级与兼容

升级至本版本后，管理员无需额外修改安全文件来开放普通聊天配置。已有的本地聊天配置白名单可保留，不影响新版目录；`file-sections`、`management-resources` 与 `console-prefixes` 继续按原规则管理。未登记的业务配置仍需显式登记，创建网页聊天也不会自动启用 Agent。

本补丁没有新增数据库结构迁移。v4.7.2-l 引入的模型上下文容量与完整输出额度规则继续有效，详见[上一版本升级要求](4.7.2-l.md#升级要求)。
