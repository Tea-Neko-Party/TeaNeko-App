状态：待发布。

## 聊天与身份资料

- 网页房间显示 Agent 等待、上下文准备、模型/工具处理及完成、取消、超时、配置错误状态；独立观察活动，不影响输入草稿。
- 应用层新增持久聊天资料服务，真实入站更新聊天名、昵称、群名片、用户 UUID、平台标识与观察时间；空资料不清除已知名称，迟到消息不覆盖新资料，群名片按聊天隔离。
- 聊天配置目录合并已知名称，Agent 工作区刷新当前目标名称；名称变化不会清空同一聊天的编辑状态。资料不作为身份或权限证明。

## 指令一览

- 主指令按名称与前缀、范围/成员/客户端、权限组、介绍分行展示；方法仅显示不同于主规则的范围、成员及权限组，参数说明独立列出。
- 规则分组使用不同背景，成员等级使用固定文字颜色，客户端名称使用稳定派生颜色。支持按聊天范围、成员与客户端筛选，子指令满足条件时保留整个指令。

## 模型管理

- 已配置模型改为摘要卡片，点击后单独弹窗编辑；添加入口只保留“＋”，类型选择和新配置均放入弹窗。型号与手动输入开关同行。原保存、应用、秘密保护及文件版本仲裁保持不变。
- DeepSeek 使用纯鲸鱼图标；Kimi、OpenAI 使用官方图标。资源随程序发布，页面不请求远程图标。
- 唯一配置路由 `id` 与协议 `adapter` 分离，同一协议可添加多条配置，各自持有型号、连接与密钥，重复路由被拒绝。旧配置省略 `adapter` 时继续使用同名协议。
- 聊天设置增加“使用模型”；`/agent models` 列出已应用路由，OWNER 可 `/agent model <路由>` 切换，`/agent model default` 恢复继承默认。切换遵守原权限、版本、取消和后续策略复核，新请求使用新选择。

## 升级

无需迁移原模型文件；新增多配置时填写各自唯一 `id` 和实际 `adapter`。模型先保存并应用，再从聊天设置或命令中选择。使用方式见[模型配置](../development/web-console-models.md)和[网页聊天](../development/web-console-chat.md)。

离线验证记录见[已归档实施计划](../plan/old/4.7.7-console-chat-models.md)；未执行真实数据库及供应商联调。
