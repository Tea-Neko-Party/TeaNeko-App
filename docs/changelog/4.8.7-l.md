# v4.8.7-l

状态：待发布，本轮未提交、打标签或推送。

## 新增与界面调整

- 图库描述改存本地，旧数据库描述自动迁出。复制原图及 `.sticker.json` 可导入另一实例，不再调用模型；保留目标已有的停用和删除决定。
- 自动表情解析增加动态、静态两种概率。默认动态 10%–100%，变化率 0.01；静态默认 20%。显式收藏、重新分析与缓存复用不抽样，两套参数可在本地配置编辑。
- Agent 参数设置按钮使用主题色。工具卡片显示实际客户端 ID，客户端专用与通用工具分别筛选；指令参数 ID、必填状态与类型分行展示。

## 修复

- 用户画像详情补齐 `eventsOnly=false`，长期条目的修改、遗忘及整理恢复请求同步修正。后端只为该可选筛选项定义缺省值，修复严格 JSON 绑定下误报参数无效；不涉及记忆数据迁移。
- 图库定时维护使用零额度通用执行预算，修复误用要求至少一次模型请求的 `LLMCallLimits` 后每分钟报错、复制导入无法执行的问题；维护仍受超时及取消约束，不调用模型。
- 聊天与定时器校验真实操作回执。空对象、错编号或错字段不再清空原请求，查询结果仍使用原操作号；聊天正文、图片和引用在确认后才清除。
- 图库查询在事务提交后一次结算输入预算。数据库重试、重复查询与并发类别不重复扣费；取消、关闭和最终失败均结束共享查询。
- 命令、客户端与内容类型目录拒绝冲突，重扫成功后整体发布；失败保留原目录。素材 I/O 错误保留安全异常类型和代码位置，不公开本机路径。
- Core 任务与 OneBot 完整处理增加在途限制。超时结束等待，但实际工作完成前继续占用容量；排队可撤销，未知写入不自动重试。数据库事务期间延迟线程中断，避免破坏回滚连接。
- Web 管理调用支持总量、单资源限额和等待期限；运行页可查看实际占用时间。修复成功回调与清理竞争时误报“已关闭”的问题。
- 网页聊天轮询使用共享读锁，初始化及修改保留排他锁。装配字段关联名称、说明和错误，三处页签统一方向键、Home/End 与 Enter/Space 操作，保留原草稿保护。
- 整理修改范围内的异步控制流和损坏注释，增加共享 IDE 格式及 `checkJavaChanges` 增量门槛。

## 升级要求

**生产启动改用 `ddl-auto=validate`。首次安装和升级前，应备份并执行配套数据库迁移。** 操作、运行账号权限与恢复方法见 [MySQL 安装、升级与恢复](../development/database-upgrades.md)，不要依赖启动自动修改表结构。

管理调用配置新增 `config/web/management.yml`。旧安装通过 `./gradlew copyTemplatesToConfig` 补充模板；已有配置不覆盖。限额、超时与原编号恢复见 [运行边界](../development/runtime-limits.md)。

图库须备份完整素材目录及身份文件。新描述引用不能由旧程序读取，回退须恢复升级前的数据库与素材备份。旧 `agent/stickers.yml` 缺少概率字段时使用上述默认值，Web 保存相关字段即可写入文件。迁移步骤与公式见[图库说明](../../src/main/java/org/zexnocs/teanekoplugin/agent/expression/sticker/README.md#本地描述与复制迁移)。

自定义事件宿主需实现 `IEventService.pushEventWithCompletion()`；有异步业务的事件通过 `IEvent.processingCompletion()` 声明实际完成阶段。管理资源必须返回涵盖实际收尾的阶段，不能使用提前超时包装代替。
