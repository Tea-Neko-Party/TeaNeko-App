# v4.7.0-l

状态：功能实现与离线验收已完成，尚未确认发布。

本版本新增 Web 管理控制台和独立网页客户端，覆盖从登录、配置管理到 Agent 检查、运行观测及聊天的完整入口。运行时继续使用原权限、配置、事件、任务和 Agent 服务。

## 新增功能

- **控制台与安全认证**：令牌登录、退出、服务端会话、CSRF、HTTPS 来源和可信代理检查。未设置管理员令牌时每次启动生成随机值并保存到受限本地文件；API、未知路径及媒体默认拒绝匿名访问。
- **平台与聊天配置**：按平台、账号、群聊/私聊定位，提供中文字段、默认预览、登记/注销、版本更新和审计。OneBot 可使用可信消息和受限联系人查询发现目录，离线仍可管理已知配置。
- **Agent 工作区**：查看真实阶段与逐段交付，检查短中长期记忆、事实证据、用户画像、人格与补正；支持原领域提供的修正、遗忘、克隆、换代、绑定和回执查询。
- **本地配置管理**：受限字段编辑、集合条目增删、预检、版本保存和独立热应用；未修改的环境模板和秘密保持原值，密钥不回显。新增网页聊天容量配置区。
- **任务与日志**：区分 Timer 规则、持久计划和单次实际运行，支持明确的暂停、恢复、取消及回执；日志支持筛选和有界保留，默认不采集正文。
- **客户端指令台**：列出显式支持管理来源的命令及详细用法，复用原命令链。OneBot 要求唯一已确认账号，发送锁定原连接，不广播、不自动改投；受理与平台消息号分别展示。
- **独立网页聊天**：持久私聊、模拟群、独立 TeaUser 档案、版本化成员/角色管理、提及、引用和认证图片。机器人消息通过原发送与逐段交付链落库；重连按游标补读，不重复入站。支持当前聊天引用图像查询、共享表情包和网页客户端表情。
- **前后端联合开发启动**：显式添加 `web-dev` Profile 后，后端就绪时自动启动本机 Vite，正常关闭或热重启时清理本实例启动的前端进程；IntelliJ 与 `bootRun` 均可使用。

## 行为与扩展变化

- 后端与本地 Vite 开发端口统一在 `application.properties` 配置，HTTP/WSS 代理和转发来源自动派生；联合启动传递 Spring 实际生效端口，支持后端端口覆盖。
- 本地 Vite 增加 `/ws/` 的 WSS 转发，保留机器认证头并声明可信 HTTPS 转发信息；OneBot 开发连接使用 `wss://localhost:5173/ws/onebot`，避免把 TLS 握手直接发送到 HTTP 后端端口。
- 启用 Web 后，启动 INFO 日志显示网站地址、令牌及快捷填表链接；登录页面支持链接自动填入和明确选择后保存浏览器令牌，继续通过原会话、防伪和服务端验证。启动凭据不进入网页日志窗口。
- 修复表情包目录工具声明的能力归属与实际注册不一致、导致应用启动失败的问题；统一使用媒体能力标识，继续遵守本轮资料与预算约束。
- Core 新增显式管理命令声明和可撤销原生来源守卫，排队启动时再次复核；网页登录不自动获得原生 OWNER 或 DEBUG。
- 网页消息在实际出队、通知监听器前再次复核来源，阻止入队后退出或变更成员的旧请求开始通知。
- 配置更新在原事务内合并当前字段，保留未知扩展值，减少旧缓存覆盖网页修改的风险。
- 文件保存与运行应用分开。模型参数及凭据按同一发布代次读取，运行失败不通过普通日志泄露秘密。
- 已提交、排队、等待外部结果、业务链结束及实际消息确认保持不同含义；未知副作用不自动重试。
- 新客户端、配置区、文件区、管理资源、工具和表达适配继续通过接口、注解、Spring 与原 scanner 扩展。发送等待任务不再以完整消息正文作为任务名称。

## 升级要求

Web 默认关闭。启用前配置正式 HTTPS 来源、管理员令牌或受限随机令牌文件，并正确设置代理及后端端口保护。启用后 OneBot 等机器连接需独立 WSS 凭据，不能使用浏览器管理会话替代。

旧 `security.yml` 需明确加入所需配置区、资源、`console-prefixes` 及 `web.chat` 文件区；缺失能力不会因代码升级自动开放。网页平台的私聊和群聊都需显式登记 Agent，默认 namespace 继续共享，演练隔离应另行绑定。

构建需要 JDK 25、Node 22.12 以上及 npm，运行已打包 JAR 不需要 Node。已有消息窗口、三层记忆、配置和媒体均依赖原数据库持久化。

## 验收边界

已执行关键事务与权限回归、真实 MVC 安全链、前端类型检查/生产构建、本机浏览器离线流程、JavaDoc、强制重编译及双 JAR 产物核对。浏览器使用离线 API 契约夹具，不代表真实后端端到端或公网验收。

正式证书/代理、真实 MySQL/JPA、多浏览器并发、OneBot、模型视觉和完整启动仍需实机验证。首期不支持多 Web 副本共享会话、真正多账号定向指令、跨重启 Core 活动账本和网页离线定时发送；网页图片统一为静态 PNG。
