# TeaNeko App v4.6.2-l

## 版本重点

新增拟人表达和实例共享表情包库。模型在一轮最终答案中描述文字分段、等待、表情包及客户端表情，后端验证后按真实聊天目标顺序发送；素材从已启用区域的真实图片中限流采集，通过一次视觉任务分类，再由本轮类别查询选择使用。

本日志对应本地版本快照；不表示已经推送远程、发布安装包或完成真实环境验收。表达、素材、相关交付及扩展实现统一归属 4.6.2-l；Web 控制台目标版本为 4.7.0-l，当前仅有设计。

## 新增功能

### 拟人表达与有序交付

- 根据人格和观察到的聊天习惯提供表达资料，支持自然语气、适量口癖、颜文字及语义分段；正式内容仍保留必要标点和格式。
- 引入带当轮标识的表达协议，在同一最终答案中描述正文、发送形式和相对等待，不为拆句或逐段发送额外调用模型。
- 命令与自动回复共用实际 client、聊天区域及机器人账号的顺序协调器，支持有界等待、取消和截止时间；每段在副作用前复核当前权限、目标及资源版本。
- 逐段记录实际平台确认，已确认重放不重复发送；无法确定交付结果时不自动补发，取消不宣称已经撤回外发消息。
- 保留普通图文与原 JSON 回复兼容路径；自主发言复用文字节奏，继续遵守原零工具合同。

### 共享表情包采集与维护

- 整个机器人实例共享图库，不按 scope、人格或记忆 namespace 分库；清除记忆不会同时删除素材。
- 已登记启用 Agent 的聊天区域默认允许被动收集人类图片；提供 sticker_collect 主动提交及 sticker_collection_status 作业查询，主动收藏同样受来源校验与额度约束。
- 下载采用受控来源、可信主机、重定向/地址检查及文件大小限制；实际解码校验类型、像素、帧数和总画布开销，动画以有界合成采样参与识别。
- 一次 SYSTEM 视觉任务完成类型判断、画面与用途描述、分类、收藏建议和综合质量评分，零工具执行；严格排除插画、照片及其他不合格内容。
- 按内容摘要去重，复用分析缓存；持久队列、容量预约、后台租约和清理状态共同处理失败、重启及迟到结果，不以重试掩盖不确定模型费用。
- 数量、类别和存储容量可配置，按质量、有限人类观察、近期使用和类别稀缺性比较替换；固定项、观察期及有效文件占用得到保护。

### 类别选图与客户端表情

- 每轮先提供当前可用类别及该 client 的原生表情目录；sticker_list 查询所选类别的完整 ID、版本和用途，超出预算时明确返回不完整，禁止截断后冒充完整授权。
- 素材许可绑定本轮请求、账号、配置和插件代次，只有真实成功且完整的工具回执可以授权最终选图；历史或其他聊天中的 ID 不能替代本轮查询。
- STICKER 与 FACE 通过独立指令和内容处理器发送，只支持 plain/reply，不与正文或 at 混发。原生表情独立于图库，不计入素材数量和人类热度。
- OneBot 上传已验证的原图字节，保持原动画，不返回宿主 file 路径或过期来源链接；文件读取与真实发送结束后释放占用。
- 平台确认后才记录机器人展示和区域回避，机器人使用不作为人类喜欢的评分证据；未知 client 不推测媒体能力。

### 图库管理与插件扩展

- 通过原 ManagementGateway 注册目录/作业/容量查询、受控预览、版本管理写入和本人操作回执四项资源。没有显式 ManagementAuthority 时默认拒绝，不新增 HTTP 或管理页面。
- 支持固定、解除固定、停用、启用、删除、恢复、修正描述/类别及后台刷新。写入采用公开版本仲裁和持久幂等；删除墓碑阻止同图自动复活，显式恢复后才重新允许。
- 刷新复用已有文件及原分析队列/额度，不重新下载旧链接，也不增加人类热度；人工修改使迟到分析失效，原停用项刷新后仍需显式启用。
- 新增同步 StickerCollectingEvent 和只读 StickerCommittedEvent，复用 Core 事件总线；第三方须在 event-plugins 中明确选择。候选来源不可替换，决策完成后冻结，提交观察不冒充可靠审计。
- 协议、指令、内容处理器、素材后端和客户端适配采用接口、注解、Spring Bean、scanner 与注册目录；重复键和不支持版本明确拒绝，保留原插件归属及启用代次。

## 配置与兼容

| 场景 | 要求与行为 |
| --- | --- |
| 新配置 | 补齐 config/agent/expression.yml、stickers.yml、media-replies.yml；已有部署不要覆盖已编辑的本地配置 |
| 模型配置 | 视觉模型及凭据仍统一在 model.yml；路由必须明确支持用户图片，缺少视觉路由的采集作业延期，不启动普通对话替代 |
| 区域开关 | expressionEnabled、stickerCollectEnabled、stickerReplyEnabled、nativeExpressionsEnabled 分别控制对应行为；收集和发送独立 |
| 元数据与文件 | 使用 TeaNekoAgentEasyData 的 agent.sticker.v1 及受控素材目录；共享数据库的副本须同时共享素材卷和身份文件 |
| 旧回复与扩展 | 原普通/JSON 图文路径保留；第三方内容仍须经过原预算、目标守卫、真实确认和资源释放，不直接绕过发送服务 |
| 管理接口 | 已有的是传输无关 SPI；登录、网页、日志界面、网页指令及独立 Web client 留给 4.7.0-l |

## 验证与验收边界

功能交付已覆盖真实 DTO 事务、共享去重、插画拒绝、动画输入边界、容量/固定保护、取消与迟到提交、类别授权、独立发送、真实逐段回执、管理授权/版本/幂等、删除/恢复及刷新仲裁。相关离线证据见[实施归档](../plan/old/agent-expression-stickers.md)。

本次版本归属整理不改业务行为，发布准备另外核对强制编译、JAR 名称及清单、生产类字节、配置模板、JavaDoc 和文档引用；历史批次中的 4.6.1-l 构建编号保留原验收事实，不作为本功能当前版本。

真实模型分类质量、OneBot face 编码和动画发送、平台上传限制、实际 MySQL、多副本共享卷及长期负载继续执行[部署验收](../development/agent-deployment.md#实机验收清单)。本版本不新增公网入口或网页鉴权，也不将 Web 设计计为已交付。
